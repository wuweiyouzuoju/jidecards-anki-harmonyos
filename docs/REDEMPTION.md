# 应用指纹与专属内容兑换

用户在「设置 → 应用指纹与兑换」复制应用识别码，发送给开发者；简洁版与实验版均有此独立入口。开发者在桌面打开 **Jidecards 兑换码工具**，粘贴指纹、选择内容、生成并复制兑换码。用户点击「使用主题兑换码」输入兑换码，成功后可以立即使用主题。

目前只有「幻彩」主题，含可关闭的动态背景，赠送给在 3.0.0 版本之前使用的老用户。用户可点击指纹说明旁的 ⓘ 查看赠送说明及复制 QQ 群号 726837065。老用户资格由开发者发码时核实，应用不会自动判断使用时间。

## 开发者工具

- 桌面入口：`Jidecards 兑换码工具.lnk`。
- 备用入口：运行 `tools/打开兑换码工具.ps1`；命令行版为 `tools/生成兑换码.cmd`。
- 图形界面仅监听本机回环地址，启动入口自动带入会话凭证，无需手动填写 token。
- 依赖本机 Node.js 24 或更新版本和当前项目路径。移动项目后需要更新桌面快捷方式。
- 相同指纹与内容会生成相同兑换码，补发时重新生成即可。

**请安全备份 `C:\Users\cheng\.jidecards-issuer\issuer-ed25519-private.pem`。** 私钥不进入项目或应用包，不要发给用户。换电脑时恢复这份私钥；不要重新生成另一份覆盖当前发行身份，否则不能为现有应用生成有效兑换码。`ui-session.json` 是临时界面会话，不需要备份。

## 规则与扩展

- 指纹是首次使用时生成的 128 位安全随机数，保存成功才展示；普通启动和覆盖升级保持不变。不读取生物指纹或硬件标识。
- 每个 Ed25519 签名兑换码绑定一个指纹与一个内容编号，永久有效，可离线兑换。重复兑换幂等。
- 应用启动时重新验签保存的凭证，成功落盘后才解锁；牌组同步和导入不携带权益。
- 重装、清数据或换机后若产生新指纹，需联系开发者补发。纯离线授权无法阻止复制完整应用数据或修改客户端。
- 专属主题的内容编号由 `ThemeCatalog.ts` 统一登记，应用验签后的权益列表与发行工具内容选项均使用这份配置。不得复用旧内容编号。旧版遇到新内容会提示更新。

## 新增主题

1. 在 `entry/src/main/ets/model/ThemeCatalog.ts` 为 `ThemeId` 增加稳定 ID，并在 `THEME_CATALOG` 登记配置。普通主题使用 `solidTheme(ID, 种子色)`，自动派生深浅色色板。
2. 在 `resources/base/element/string.json` 和 `resources/en_US/element/string.json` 添加 `theme_color_<ID>` 名称。主题选择页与发行工具自动读取。
3. 可选填写预览色、进度/牌组渐变、强调文字色、深浅页面底色。主操作玻璃由主题种子色或幻彩强调色自动派生。留空沿用普通主题；不要在页面里添加主题 ID 判断。
4. 动态彩雾使用三张带透明边缘的 PNG，放入 `resources/rawfile/themes`，在 `backgroundTextures` 填相对路径，`backgroundCycleMs` 控制每轮速度。此渲染器支持固定三层彩雾；新的动画形态需另行扩展渲染器。
5. 专属主题设置唯一的 `requiredContent`（如 `theme-xxx`）；免费主题留空。无需修改验签、存储或发行工具白名单；更新 ⓘ 的赠送说明后重新启动发行工具即可显示新选项。

`ThemeBackground.ets` 只在首页根 `Stack` 中创建一次，位于 `Navigation` 外层。页面使用 `PAGE_SURFACE_KEY`，`NavDestination` 设透明；卡片和弹窗仍使用各自表面色。新增导航页面时沿用此方式，禁止再创建页面独立背景。窗口前后台与背景可见性控制播放；切页不改变随机目标、位置或亮度。`ThemeBackgroundMotion.ts` 负责运动目标，`ThemeVisuals.ets` 负责把配置色转换成 ArkUI 渐变。

## 幻彩外观

浅色使用近白底上的蓝、青、紫、粉色雾，深色使用暗底光雾；三张预生成的透明彩雾纹理每 6 秒随机切换平移、缩放和透明度目标，叠加产生颜色变化；帧间由系统合成动画执行，不使用逐帧 ArkTS 状态回调或实时色相滤镜。关闭动态后保留静态画面，后台与根背景不可见时暂停动画。主页、设置与学习等导航页面共用同一背景，切页持续播放，不改卡面、正文或新卡/学习中/复习计数语义色。

主页使用完整彩虹进度条、稳定的牌组渐变侧边条和彩色新建按钮。开始学习和显示答案（固定底栏、浮动栏）共同使用 PrimaryGlassSurface 常驻主题玻璃，包括按下态；主文字使用对应主题色，幻彩使用多色文字。进度条仍遵循真实进度；用户手动设置的牌组色调保持优先。

主题强调文字由 `ThemeText.ets` 的 `ThemeTextSpans` 统一渲染，放入原生 `Text` 后保留字号、字重、截断与本地化参数。页面订阅 `THEME_TEXT_COLORS_KEY`；普通主题、禁用项、危险操作和数据文字（时间、计数、百分比、号码、链接）传空色板，沿用原单色。幻彩标签在 `lightActionColors` / `darkActionColors` 的前两色之间按字符位置线性插值，整段读作一条连续渐变，少于 3 个字的标签直接用首色；禁止按 `index % colors.length` 逐字轮换色板，四个色相跳色会被读成"一个数字一个颜色"。

选中牌组透出彩雾背景，以高光和描边形成玻璃感；轻操作按钮及评分按钮使用 `GlassSurface.ets` 共用按下态，以半透明材料呈现已有的柔化背景，不做实时背景模糊，避免按下与切页时重复采样。玻璃底色按用户反馈加厚：浅色为 50%–70% 不透明度的乳白层，深色为 65%–80% 不透明度的暗色层；两者通过 `GLASS_COLORS_KEY` 随外观模式更新。避免对整个控件设置 opacity，文字和计数保持清晰。开始学习、显示答案使用 PRIMARY_GLASS_KEY：正常约84%不透明度，按下约90%，普通主题轻染种子色，幻彩轻染多色，深浅模式自动匹配。

导航淡入淡出使用 EaseOut 和 60fps 期望帧率；慢速动态背景请求 30fps（范围 15–30fps），降低常驻绘制负载，转场期间冻结背景，结束后继续流动。实际帧率由设备决定，目标帧率减半不代表整机耗电减半。首页与设置内容顶部统一为 `应用尺寸.pageContentTopInset`（8vp），加上工具栏底部 8vp，按钮下缘到首张卡片的间距均为 16vp。

多色文字节点的 key 包含实际色值，切换主题或深浅模式时重新着色。新建牌组所在的共用按钮在组件内直接绘制 Span，避免构建器参数与旧节点复用导致色彩滞留。
