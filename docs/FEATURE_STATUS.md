# 易混淆功能的当前状态

用于功能盘点、与 Anki/AnkiDroid 对照以及新增功能前的核查。本文是源码导航，不替代源码；功能变更时同步更新对应条目。只记录容易把“已有能力”“已接入流程”“已有设置入口”混为一谈的项目。

## 页面操作边界（2026-09-19）

- 首页将集合占用、弹层占用、导航/前台位置映射到 `HomeActivityPolicy`，公告和自动同步使用统一准入事实。公告请求由 `HomeAnnouncementController` 保存待展示结果，创建/编辑/导入、系统确认窗口、详情或其他页面期间不抢占；状态释放后继续公告 → 云端引导 → 欢迎流程，未展示时不提前记录欢迎已读。系统返回不关闭正在写入的数据操作面板。
- 云端下载由 `CloudDeckImportController` 串行处理固定任务列表，保留前次成功项、逐项记录失败、忽略过期进度回调。首页负责 Kit 适配、展示、导入后刷新和配额保存；配额保存完成前保持忙碌。不是取消导入或改变配额规则。
- 浏览页批量删除/改牌组/旗标/暂停/恢复/到期/重新定位/笔记类型、字段保存、查找替换、标签写入，共用 `runBrowserOperation` 和 `BrowserOperationController`。操作捕获模式、ID、查询/选择代次；写入互斥，仍可更换搜索和选择，旧完成不能清空新选择或覆盖新批量错误。
- 离页使读取失效，已接受的写入继续完成。`AutoSyncScheduler.beginOperation/endOperation` 保持占用直到写入收尾，成功后重新广播首页刷新并请求同步；不能只依赖离页瞬间的刷新。该占用不冒充学习会话，不改变学习完成页语义。
- 编辑、卡片信息、笔记类型映射及异步操作菜单检查请求代次/选择上下文；预览固定进入时 ID 顺序。搜索捕获本次输入，分页按已消费 ID 数前进，坏行不会使正常行重复加载，旧分页不能解除新请求的忙碌状态。选中范围解析失败不执行部分查找替换。
- 学习页保留既有 `StudySessionController`、`StudyTiming`、`CardAudioSession` 与页面生命周期分工，本轮未迁移学习时序代码。
- 行为验证入口：`tools/tests/page-operation-boundaries.test.mjs`，并复用 `browser-batch-runtime`、`browser-presentation`、`sync-automatic`、学习生命周期测试。验证为真实页面方法配合可控异步依赖；设备交互尚待真机实测。

## 卡片样式与脚本（2026-09-19）

- APKG 是牌组包，CSS 是笔记类型的卡片样式；单独的 `.css` 文件不包含牌组数据。模板 CSS 已由 Core 渲染结果传入学习和浏览预览共用的 `学习卡片HTML构建器.ets`。
- 模板样式与应用默认/兜底样式分别包装，兼容样式字段中的 `</style><script>`，防止应用 CSS 变成正文。保留既有配色层叠顺序，不删除模板脚本。
- 学习和预览都通过 `utils/CardAssetResponse.ets` 加载 HAP 内置 jQuery 3.7.1（与 Anki 锁定版本一致）和 MathJax；jQuery 在模板脚本前同步加载，不依赖 CDN。保留第三方完整发行文件和许可。
- 验证边界：1069 项 Node 测试、31 项真实浏览器回归和完整构建通过；用户提供的 `blank.apkg` 抽样三张，明暗主题正反面共 12 种组合可显示题目、四个选项、答案解析，选择/对比答案无脚本报错。该牌组须从作者服务获取脚本，离线时题目仍为空；不是纯离线牌组。未验证全部卡片、全部第三方牌组或鸿蒙真机，不代表支持所有 Anki 插件/API。
- 回归入口：`tools/tests/card-template-style.test.mjs`、`tools/test-card-template-browser.mjs`、`tools/tests/math-rendering.test.mjs`。上游依据：[模板样式包装](https://github.com/ankitects/anki/blob/main/pylib/anki/template.py)、[reviewer 的 jQuery 导出](https://github.com/ankitects/anki/blob/main/ts/reviewer/index.ts)。

## 自动同步

手动同步返回首页后保持唤醒，优先于尚未展示的公告和引导；已打开弹窗、学习/编辑、导入及数据操作仍互斥。排队提示显示真实阻挡原因，已有同步任务时直接打开该任务详情，不覆盖进度。


已接入且默认开启，设置页可关闭。`model/AutoSyncScheduler.ts` 合并学习写入产生的同步意图，`pages/首页.ets` 在安全空闲时执行既有同步流程；同步更新跨设备数据，不保存可供回滚的长期历史版本，不能当作自动历史备份。

手动同步与自动同步共用根宿主；设置页发起后返回首页，顶栏“更多”和“新建牌组”之间显示手动任务进度、失败重试或待处理冲突，详情可随时收起。自动传输保持静默，首页延后 3 秒检查；开始学习取消未执行检查，进行中的增量同步通过独立原生取消通道回滚后让路，未同步意图保留，手动重试不受自动同步关闭影响。媒体阶段继续传输；未确认的全量冲突不锁学习，确认覆盖前重新检查方向和端点。已经明确发起的全量替换仍保护数据库直至完成，不能承诺零等待。同步后的 FSRS 提醒延后到空闲首页。

原生 `AbortSync` 绕过普通调用锁及 NAPI 工作线程队列，仅发送 Core 取消信号；普通数据库调用仍串行。取消句柄注册竞态由独占期间重试处理，原调用落定且取消信号完成后释放集合。验证入口：`sync-automatic.test.mjs`、Rust registry 并发测试及真实 Anki Core 本地慢响应 HTTP 取消测试。

统计页可以在同步期间直接打开，先展示首页已取得的完整统计快照，再等集合同步释放后查询最新数据；不等待媒体传输或首页刷新。快照携带统计天数，范围不匹配时不复用；无快照时仍显示加载态。刷新完成前图表内控件暂不可修改，但可以滚动查看、返回或切换统计天数。离页后取消尚未执行的查询，旧响应不能覆盖新查询。回归见 `stats-entry-runtime.test.mjs`。

## 删除牌组与媒体清理

- 删除牌组已接入 Core `decks/remove.rs`：递归处理子牌组，普通牌组删除卡片和孤立笔记，筛选牌组归还卡片；默认牌组保留并重置名称。RPC 的 count 是删除的**卡片数**，不是牌组数。
- Core 支持该操作的撤销，但首页没有通用撤销入口；确认提示不承诺“首页顶部撤销”。
- 媒体由集合共享，删除牌组不连带删除文件，这是预期语义。已有完整清理入口：设置 → 数据管理 → 媒体管理 → 检查媒体 → 未使用文件移入回收站 → 清空回收站；清空前可恢复回收站。
- 核查入口：`backend/牌组服务.ts`、`pages/首页.ets`、`components/settings/媒体管理面板.ets`、`backend/媒体服务.ts`。不能把媒体保留判断成媒体清理接口未接入。

## 笔记模式批量操作与学习自动播放

- Web 卡片本地音视频：学习页与预览页共用 `媒体响应助手.interceptMediaRequest`，支持单范围 `Range`（闭合、开放、后缀）及 `206/416`、`HEAD`。完整资源由 ArkWeb 文件句柄读取，部分区间异步读取并校验实际长度；图片、字体、脚本继续经过同一入口。`media-response.test.mjs` 验证 HTTP 元信息、实际正文、并发、短读与句柄归属；用户反馈的进度条拖动是否恢复仍需真机验证，不据隔离测试宣称已解决所有触摸问题。

- 浏览页删除、改牌组、设置标志已复用 `笔记服务.获取笔记的卡片`，展开全部兄弟卡并去重。删除完成重新查询后端结果，不用本地移除行模拟删除；查询或写入失败保留选择并提示错误。
- 学习页“关闭自动播放”已接入：`AnkiStudySessionBackend.studyOptions` 读取当前卡片实际牌组的配置（筛选卡使用原牌组），`StudySessionController` 将展示选项纳入当前快照，学习页自动播放遵循开关，按钮/快捷键手动重播仍可使用。每次加载重新读配置，过期响应不能更新当前卡面。
- 回归入口：`browser-batch-runtime.test.mjs`、`study-autoplay-backend.test.mjs`、`study-lifecycle.test.mjs`、`study-session-controller.test.mjs`；验证为隔离行为测试及构建，设备表现仍需实测。
