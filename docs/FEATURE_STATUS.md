## 图片遮罩兼容与编辑（2026-10-02）

- 学习和预览共用 `ImageOcclusionRendering.ts`，支持矩形、椭圆、多边形、旋转、文字、两种遮盖模式和答案轮廓，遵循锁定 Anki 26.05 的属性与几何；大图画布限制为 4096² 像素。
- 新建与现有笔记共用图形编辑器，支持分组编号、移动、缩放、矩形/椭圆/文字旋转、删除、清空、撤销/重做与未保存退出确认；文字使用 c0，不生成考查卡片。现有笔记按 Core 字段位置读取，通过原笔记保存入口提交，编辑器只持有草稿。
- 原始片段未修改时逐字回写，修改保留未知属性、其他字段与未变动的多卡编号。删除或重新分组交由 Core 决定卡片变化，不主动重建卡片或清除复习记录。
- 直接行为、真实浏览器像素和真实 Core 调度后编辑测试见[学习与媒体](development/study-media.md#图片遮罩)。原生 ArkUI 手势、系统返回、输入法和窄屏布局仍需设备验收，复习卡面的遮罩切换按钮保持现有隐藏状态。

## 笔记类型与文本导出（2026-10-02）

- 设置的笔记类型管理可从六种 Core 标准类型创建，或克隆现有类型；保留字段、模板、CSS 和未知配置。编辑器支持模板新增、删除、重排及样例正反面预览，Cloze 保留一个模板。模板身份按原 `ord` 保留，新模板为 `null`，结构变更展示具体字段/模板及受影响笔记/卡片数量，未删除卡片保留学习记录；字段结构修改须先保存再预览。
- 新增和编辑可预览未保存字段、多模板及各个 Cloze 编号，包含待存图片/音频与已有媒体。使用 Core 未提交渲染，复用学习的 HTML、数学和媒体链路，临时文件只在预览缓存中，不保存笔记或改变媒体库。关闭预览保留草稿，所有返回入口共用退出保护。
- 设置及牌组菜单的导出面板可选择 APKG、笔记文本、卡片文本。文本由 Core 生成 UTF-8 制表符分隔 `.txt`；笔记可选 HTML、标签、牌组、类型和 GUID，卡片导出渲染正反面。文本不包含媒体文件和复习进度。
- 责任、回归与设备验收边界见[浏览与编辑](development/browser-stats.md)和[数据迁移](development/import-data.md)。当前源码能力不表示本轮已完成真机交互验收。

## 页面操作边界（2026-09-19）

当前发布状态：123 云盘远程公告由 `model/官方公告配置.ts` 的 `OFFICIAL_ANNOUNCEMENTS_ENABLED = false` 暂停；不请求、不调度、不展示，保留已读记录。下述公告协调能力在开关启用时运行，本地入门独立运行；幻彩赠送提醒已在 3.0.20 移除。

- 首页将集合占用、弹层占用、导航/前台位置映射到 `HomeActivityPolicy`，公告和自动同步使用统一准入事实。公告请求由 `HomeAnnouncementController` 保存待展示结果，创建/编辑/导入、系统确认窗口、详情或其他页面期间不抢占；状态释放后继续公告 → 入门介绍流程（牌组直链渠道已暂停），未展示时不提前记录欢迎已读。系统返回不关闭正在写入的数据操作面板。
- 云端下载由 `CloudDeckImportController` 串行处理固定任务列表，保留前次成功项、逐项记录失败、忽略过期进度回调。首页负责 Kit 适配、展示、导入后刷新和配额保存；配额保存完成前保持忙碌。不是取消导入或改变配额规则。
- 浏览页批量删除/改牌组/旗标/暂停/恢复/到期/重新定位/笔记类型、字段保存、查找替换、标签写入，共用 `runBrowserOperation` 和 `BrowserOperationController`。操作捕获模式、ID、查询/选择代次；写入互斥，仍可更换搜索和选择，旧完成不能清空新选择或覆盖新批量错误。
- 离页使读取失效，已接受的写入继续完成。`AutoSyncScheduler.beginOperation/endOperation` 保持占用直到写入收尾，成功后重新广播首页刷新并请求同步；不能只依赖离页瞬间的刷新。该占用不冒充学习会话，不改变学习完成页语义。
- 编辑、卡片信息、笔记类型映射及异步操作菜单检查请求代次/选择上下文；预览固定进入时 ID 顺序。搜索捕获本次输入，分页按已消费 ID 数前进，坏行不会使正常行重复加载，旧分页不能解除新请求的忙碌状态。选中范围解析失败不执行部分查找替换。
- 学习页保留既有 `StudySessionController`、`StudyTiming`、`CardAudioSession` 与页面生命周期分工，本轮未迁移学习时序代码。
- 行为验证入口：`tools/tests/page-operation-boundaries.test.mjs`，并复用 `browser-batch-runtime`、`browser-presentation`、`sync-automatic`、学习生命周期测试。验证为真实页面方法配合可控异步依赖；设备交互尚待真机实测。

## 自动同步

手动同步返回首页后保持唤醒，优先于尚未展示的公告和引导；已打开弹窗、学习/编辑、导入及数据操作仍互斥。排队提示显示真实阻挡原因，已有同步任务时直接打开该任务详情，不覆盖进度。


已接入且默认关闭，设置页确认体验影响后可自行开启，保留已保存的选择。首页“更多 → 同步”与设置页“立即同步”共用手动同步入口。`model/AutoSyncScheduler.ts` 合并学习写入产生的同步意图，`pages/首页.ets` 在安全空闲时执行既有同步流程；同步更新跨设备数据，不保存可供回滚的长期历史版本，不能当作自动历史备份。

手动同步与自动同步共用根宿主；设置页发起后返回首页，顶栏“更多”和“新建牌组”之间显示手动任务进度、失败重试或待处理冲突，详情可随时收起。自动传输保持静默，首页延后 3 秒检查；开始学习取消未执行检查，进行中的增量同步通过独立原生取消通道回滚后让路，未同步意图保留，手动重试不受自动同步关闭影响。媒体阶段继续传输；未确认的全量冲突不锁学习，确认覆盖前重新检查方向和端点。已经明确发起的全量替换仍保护数据库直至完成，不能承诺零等待。同步后的 FSRS 提醒延后到空闲首页。

原生 `AbortSync` 绕过普通调用锁及 NAPI 工作线程队列，仅发送 Core 取消信号；普通数据库调用仍串行。取消句柄注册竞态由独占期间重试处理，原调用落定且取消信号完成后释放集合。验证入口：`sync-automatic.test.mjs`、Rust registry 并发测试及真实 Anki Core 本地慢响应 HTTP 取消测试。

## 集合维护与调度兼容

首页和浏览器“更多 → 回退”显示 Core 的实际操作名称和可用状态；提交在原生集合锁内重新校验历史，历史变化时要求刷新。浏览多选“重置为新卡”支持恢复原新卡位置和重置复习／遗忘计数；Notes 模式展开全部兄弟卡，保留身份和复习日志，操作可以撤销。

媒体管理检查结果提供受影响笔记浏览与 missing-media 打标。ID 按 256 条原生分页传输；打标再次核验确认集合内仍缺媒体的笔记，单次 Core 事务保留其他标签，可以撤销。浏览器最终查询仍使用完整 ID 列表，大库查询占用随受影响笔记数增长。

自定义调度支持集合级同步 JavaScript：脚本执行后按钮与评分采用同一候选状态，原生校验保留 current 与未修改状态字段。完整模式可编辑或清空脚本；JIDE 读取真实配置状态和支持范围。执行失败才提示并要求确认标准调度；不支持 await、DOM 或网络。边界与验证入口见[执行决策](decisions/2026-10-07-custom-scheduling.md)。
