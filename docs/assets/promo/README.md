## 制作约束

- 画面来自宣传专用模拟器中的真实运行截图，只做等比缩放、圆角遮罩和明确标注的局部放大，不重绘界面，不修改图表数字。
- 统计页数据来自示例牌组的真实复习；提醒为未保存的编辑状态。同步页展示的是未登录状态的设置，不表示已登录或同步成功。
- 云端牌组来源以文字说明，不伪造云端列表。
- 图片保持交付时的原始字节，未重新压缩。界面有较大改版时整套重拍，不单张替换，以保证三端一致。
