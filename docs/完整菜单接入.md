# 完整菜单与玻璃弹层

2026-11-04，0.2.15：从当日 JideCards 工作区提取实际呈现。原产品组件改为薄适配；记得闪卡和记得记忆宫殿消费同一实现，不能继续复制菜单绘制。来源与改造范围见 [provenance.json](../provenance.json)。

| 公共入口 | 唯一责任 |
| --- | --- |
| SharedGlassPanel | 实测面板与融合宿主、真实纹理就绪、内容显现、离页失效、原生字与玻璃的共同转场 |
| SharedGlassBubblePanel | 同一指向轮廓、光学裁切、尖角方向和缩放中心 |
| SharedAnchoredMenu | 窗口到宿主坐标转换、工具栏左右边缘、安全区/键盘避让、有限滚动、外部点击及关闭请求 |
| SharedMenuItem / SharedActionMenuList | 图文整组居中/靠左、44vp行、分隔线、可用/选中/危险状态、当前条目ID重验、划选目标 |
| SharedPopupSurface | 无重复模糊和阴影的中性材质、明暗轮廓、扁平透明度、隐藏后清理旧效果 |

`SharedMenuTheme` 显式传入材质、深色、前后台、API能力、减少动态效果、透明度及语义色。基础库不读产品 AppStorage，不导入产品资源或服务。产品薄适配负责实际资源解析、采样源引用的获取/释放、触发按钮交接、SurfaceTransition偏好和菜单路由会话；声明、业务回调、持久化仍在原产品。

`toolbarBounds` 是窗口坐标：left为完整工具栏左缘，top为按钮组底缘加一次8vp间隔，width为完整定位区域宽度。宿主只扣除一次自身窗口偏移；alignEnd决定左右对齐。不要把单个44vp按钮宽度当作菜单限宽。工具栏菜单圆角22vp，普通菜单18vp；图文间隔8vp，左右10vp，文字15vp。指向菜单继续用18vp轮廓与同一箭头几何。

采样源只包含页面内容。菜单是源的兄弟层，不能截取自己或父菜单。closeRequest统一走onClose；按住划选时宿主、列表和行必须传同一个scope，路由仍由产品现有会话承接。父菜单变成透明内容壳后，最初取得的采样引用仍须等真正销毁才释放。

[独立可编译样例](../examples/GlassShowcase.ets)实际组合SharedAnchoredMenu与SharedActionMenuList，不以手写文字和单片玻璃代替菜单。当前实际方法回归由JideCards的shared-menu-harness执行公共源码，涵盖准备/离页/迟到回调、偏移与安全区、当前ID重验、轮廓、缩放中心和来源生命周期；编译与设备视觉验收分别记录。

普通内容与控件可显式采用SharedSurface的series档及opacityPercent/nested输入。原legacy档保留已有消费者的兼容参数，不能自动把其他产品的既有表面改成新档。系列材质的默认值、资源、持久化键属于产品输入。
