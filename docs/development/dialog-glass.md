# 自绘弹窗玻璃接入

基础契约见[系列弹窗玻璃](../../../记得系列基础/docs/弹窗玻璃.md)。光学、半分辨率采样与资源释放由公共 HAR 的 SharedGlassBackdrop 拥有；产品不再保留 GlassOptics 的第二份实现。

## 责任与覆盖

| 宿主 | 实际调用范围 | 保留的业务责任 |
| --- | --- | --- |
| GlassSource | 首页正文、学习、浏览、统计、提醒、添加笔记、JIDE、设置、牌组选项、独立编辑、卡片预览、全屏草稿/模板预览 | 仅正文与页面可见性；透明区域在基础会话中合成唯一根背景，宽屏内嵌编辑器沿用浏览完整正文 |
| GlassPanel / DialogFrame | 公共表单、选择、确认、帮助、目录、引用、学习设置及全部 NativeDialogHost 自定义窗口 | 原有草稿、忙碌、提交、返回、键盘、安全区与叠层尺寸 |
| AnchoredMenu | 首页更多/新建、JIDE更多、浏览视图、设置模式、预览范围、牌组操作 | 原有锚点、菜单宽度、限高、滚动和划选 |
| CardActionMenu / MenuBubble / GlassBubblePanel | 学习、卡片预览、浏览动作、多列分组和深层旗帜菜单 | 完整动作树、独立分组高度、分支展开和顶层返回 |
| SurfaceSelect | 全部公共枚举选择器 | 原生锚点定位、选中值和有效性守卫 |
| 白板工具 Popup | 原版笔/橡皮、官方白板透明度 | 原生定位与关闭；共享箭头轮廓与材质 |
| 独立旧面板 | AnkiWeb引导、欢迎、公告、云端牌组、同步、添加笔记、卡片信息、自定义学习、媒体管理、首页奖励 | 原尺寸和内容流程；只更换表面宿主 |
| 兑换 | 原生自定义窗口 + DialogFrame | 保留输入、在途操作禁止退出、兑换结果和应用主题动作 |

所有纹理均为内容下面的直接子层。普通面板由宿主明确宽度/限宽，正文决定高度；纹理、描边位于零布局尺寸的绝对层，不能以面板上次尺寸参与下次测量。箭头轮廓从宿主的同一 M/L/Q/C/Z 路径传入基础库，裁剪和折射使用同一轮廓，不把矩形纹理贴在异形表面上。

GlassPanel统一持有0.01准备透明度、首张绘制就绪与250ms超时锁定；玻璃与文字同一容器展开。NativeDialogHost原生进入时长为0，内容拥有进入，关闭仍由原窗口和业务守卫管理。扁平、API21–22、无可用源与采样失败保留现有材质；展开后不补入迟到折射。深色显式传入基础库，与浅色共用纹理。

## 系统例外

`showAlertDialog`、`promptAction.showDialog/showActionMenu`、系统 Toast、权限/授权、文件/照片/颜色等系统选择器保留系统渲染，不替换系统窗口。它们与应用 `@CustomDialog` 不是同类；后者已经通过公共宿主接入。页面卡片、搜索框、编辑轮盘、结果提示条、全屏加载/错误页属于内联或页面材质，不改成模态弹窗。

## 回归与验收入口

`tools/tests/shared-glass-integration.test.mjs` 执行真实准备逻辑，覆盖首次纹理、超时锁定、离开后的迟到回调、旧API降级和四向箭头光学。`glass-optics.test.mjs` 直接导入公共光学；`native-dialog-host.test.mjs` 验证原生窗口身份与关闭守卫。菜单动作树和几何继续由原 `home-deck-menu`、`menu-slide`、`study-menu-actions` 与 `ui-shell-deck-actions` 回归保护。

构建顺序：基础库 `npm run build:harmony` → `npm run sync:consumers -- jidecards` → 产品 `devecocli build`。只同步闪卡。设备仅使用 `hdc -t <serial> install -r <signed-hap>`，不得卸载清数据。

2026-10-30迁移中发现并修正两类布局反馈：纹理按面板尺寸反向撑大含边框容器；箭头容器用初始高度限制正文，裁掉旗帜/卡片操作并污染相邻分组位置。当前设计把背景和描边排除出测量，以真实正文作为高度来源。设备验收必须包含持续静置、反复开关、标记/旗帜/卡片操作交叉展开、明暗与宽窄窗口，不能用短暂正常的单张截图代替。
