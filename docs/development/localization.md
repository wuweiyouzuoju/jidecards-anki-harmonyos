# 地区语言与长文案布局

`model/AppLocales.ts` 是界面、设置和 JIDE 的语言代码、资源目录与原生名称的共同入口。语言列表前三项固定为简体中文、繁體中文（中國香港）、繁體中文（中國台灣），其后为英国英语、美国英语、意大利语、日语、越南语、韩语、俄语、德语和法语。旧 `en` 偏好解析为 `en-US`，香港与台湾不合并。`语言存储.ets` 使用系统应用语言偏好持久化，`EntryAbility` 在配置变化时发布 `系统语言`，文字订阅该键就地刷新，不以整页重建丢弃草稿。公告服务器仍只有中英两种内容，通过独立的 `announcementLocale` 明确回退；这不改变界面语言。

## 文案与格式的责任

语言选择框的选中索引与显示名称都从 `当前语言模式()` 读取同一系统偏好；`系统语言` 是配置通知的观察键，不能单独作为选择框当前值。重新打开设置时即使观察键还保留旧值，也不能显示另一种语言。索引查找先读取一次偏好，禁止在每个候选项中重复调用系统 API。系统读失败时两项都退回观察键；设置相同语言在存储入口直接返回，避免原生 Select 的重复回调继续触发配置通知。

选择行只呈现宿主传入的选项、索引和完整名称；宿主负责用相同状态生成这三项。批量上限的存储支持 1–1000，恢复非预设整数时将当前值加入选项并选中，不高亮为 1000，也不重写已保存值。JIDE 仍观察原 `batch_limit` 数字，设置能力和保存协议不变。

每个目录的 `element/string.json` 必须与 base 全键对应、唯一、非空，并保留格式参数、提醒模板变量、URL 和技术语法。所有新增文案都补齐这十二份资源。品牌、协议字段、用户输入和已有卡片内容保留原值。香港与台湾文案在繁体转换后另行检查术语，提醒模板统一保留运行时支持的 `{{new}}`、`{{review}}`。英国英语保留软件术语的英式拼写，许可证正式名称保留原名。

显示数字、百分比、紧凑计数和日期共用 `utils/LocaleFormatting.ts`，传入完整地区代码；`zh-HK`、`zh-TW`、`en-GB`、`en-US` 不降为语言前缀。存储时间、文件名、协议数字及 HTML/SVG 数值仍使用机器格式。通知生成时使用当前语言资源和地区数字，用户自定义标题与正文不重写。桌面卡片的数据绑定随快照传入实际资源文字，首次空态也通过资源管理器生成，避免只随旧数据缓存语言。

## 布局的不变量

主要文字动作按内容增高，44vp 为最小触摸高度，文字在剩余宽度内换行。辅助选择控件有界限宽并保留完整无障碍名称，控件高度通过 `SelectStyle.controlHeightFor` 跟随实际 fp 缩放；不能通过无限缩小字号适配长译文。

长操作确认使用 `TextActionDialog`：正文滚动、完整动作纵向排列，首页宽度建议保留原来的一次确认、持久化与返回守卫。其名称和目标由 `deckLayoutSuggestion` 同时提供给 UI 与实际 JIDE 观察。其余原生确认统一使用 `buttons` 数组和 `DialogButtonDirection.AUTO`，让系统根据文字宽度切换排列；禁止重新使用固定的 `primaryButton/secondaryButton` 双列。`ui-confirmation-layout` 持续检查这些入口，原取消、危险色、冻结目标和迟到回调由原领域测试验证。七日复习图表按当前语言标签的实际测量宽度排列，宽度不足时横向滚动，不把 Today 拆成两行，滚动条另留底部空间。

新增/编辑顶栏共用 NoteEditorHeader，预览动作保留在标题右侧同一行，完整标签可换行并按内容增高。首页摘要的卡片和标题区域、牌组行与详情标签跟随实际 fp 缩放分配空间；`homeSummaryStacksMetrics` 在放大字号后的窄窗口将标题与牌组数分行、三列统计改为三行，数字与完整标签并排，统计正文按自然高度排列并在需要时滚动，不能用等分高度挤压多行标签。详情数字不与标签重叠。Text 的数值 `lineHeight` 单位是fp，系统已经缩放，禁止再乘字体比例；牌组容器的vp高度另行跟随字体缩放。

`NoteFieldEditor` 保留由当前字段拥有的窗口边缘轮盘，工具图标与两行名称位于原圆形按钮内；字号与标题沿外弧展开，字段下方不新增工具区。宽字段的模式按钮置于右侧并对齐输入栏上下边界，窄字段顶部横排；完整模式名称按自然高度显示。字段切换、禁用、选区代次、源码往返及焦点保护仍归字段编辑器。UI 与 JIDE 的位置、名称与状态来自 `NoteFieldEditing` 和实际界面观察。

## 可复现验证

```powershell
npm test -- ui
npm test -- browser
npm run verify -- repo
npm run build:app -- -SkipRust -Architecture x64
npm run build:app -- -Test -SkipRust -Architecture x64
hdc -t <connect-key> install -r entry/build/default/outputs/default/entry-default-signed.hap
node tools/test-locales-device.mjs <connect-key> all
```

`i18n-contract` 检查全部语言的键、空值、占位符以及嵌套 UI 字面量；`i18n-formatting` 执行地区格式与提醒变量；`ui-locale-refresh` 检查切换与草稿身份；`note-rich-editor`、`note-editor-wheel` 执行真实选区和工具回调。`tools/test-suites.mjs` 将本地化契约纳入 UI 和仓库套件，CI 的 `verify -- repo` 使用同一发现入口。

`ui-locale-refresh` 还执行生产语言显示绑定与索引，覆盖十二种已保存偏好和十二种过期观察值的组合、重新实例化、旧语言别名及重复保存回调。`ui-select-layout` 执行批量上限的真实选择行属性与回调，检查非预设恢复值、无效索引和禁用后的迟到回调。三应用选择调用点清单、本次签名包与原始日志在 `D:/Projects/output/select-state-audit-20261021`；主机回归不证明设备配置通知时序或切换耗时。

设备工具在空闲首页运行，每次会重启应用；先完成或取消未保存的表单。只覆盖安装测试 HAP，不卸载、不清数据，不创建用户笔记。每种语言分别以1/2倍应用字体打开实际主应用首页，核对资源管理器实际选中的五个资源并等待真实首页数据进入 ready/empty，再确认本地化首页文字可见，保存截图、日志与 `matrix-home.json` 到 `.local/locale-acceptance/device/<connect-key>/`，结束时恢复语言与字体。窗口宽度来自所选设备，需要在手机、平板和系统分屏分别执行；运行成功不证明截图中全部文字都没有截断。

这里的两倍字号是测试运行器通过 `ApplicationContext.setFontSizeScale(2)` 临时开启的压力条件，并非产品设置中的独立开关。原字号和语言在 finally 中恢复；截图分享时须标明压力条件，不能把测试放大后的界面当作默认界面，或只凭资源切换成功宣称视觉验收通过。

`node tools/test-locales-device.mjs <connect-key> en-US 2 layout_suggestion` 单独验收完整按钮；`all all layout_suggestion` 批量运行全部语言和两档字体。这个场景只临时更改当前进程的布局与提示状态，展示实际首页的宽度建议，不点击操作、不写布局偏好，并在结束时恢复；需要现有牌组在单列宽布局中实际溢出，否则用例失败。截图与记录写入 `matrix-layout_suggestion.json`。`all all double_columns` 临时展示双列宽样式，用于检查整棵子树按较短列接续，不写布局偏好。手机实际新增页已检查日语工具的展开/收起及后续粘滞说明不重叠；软键盘、鼠标、深色、自定义字体与系统分屏仍需逐场景验收。脚本失败和未执行的场景不得记为通过。

译文由本模型直接完成并逐项对照，未使用外部翻译服务；代码契约及设备显示验收不等于目标语言母语者审校。

双列验收同时检查实际 FlowItem 和其内部卡片的边界；仅检查外层组宽度不足以发现子卡片越界。FlowItem 必须显式约束为100%列宽，内层百分比才以列为参照。手机上已实际展开长父牌组，核对后续顶级牌组连续填入较短右列，并恢复原展开状态。
