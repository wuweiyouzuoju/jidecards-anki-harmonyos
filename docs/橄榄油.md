# 橄榄油：系列公共动效

2026-10-29，正式HAR 0.2.2；与iOS JideFoundation内橄榄油采用同一核心时序与形变公式。

## 接入入口

```typescript
import { OliveOil, OliveOilSurface, OliveOilSession, createOliveOilSession,
  oliveOilAnimation, OliveGeometry, OliveState } from 'jide_foundation';
```

| 模块 | 责任 |
| --- | --- |
| `src/core/OliveOil.ts` | 纯轮廓计算：cluster卡片群组、group横纵按钮组与单目的地移动、radial轮盘吸附、ligament相邻模块连接 |
| `src/core/OliveOilSession.ts` | 先隐藏内容、等待几何、主体形变、提前显现内容、结束解锁；导航拒绝重入，局部组可重定向；取消旧回调和销毁 |
| `OliveOilSurface` | ArkUI Path的原生可动画属性；每帧按progress重算轮廓，不对不同拓扑的路径字符串作插值；无点击/导航副作用 |
| `createOliveOilSession` / `oliveOilAnimation` | 计时器平台适配与原生曲线；宿主仍持有session、进度、显示目标和可见锚点 |
| [可运行样例](../examples/OliveOilShowcase.ets) | 卡片、评分和轮盘三种演示，播放/返回、手动逐帧、减少动态效果与深浅色 |

基础导出不读取产品的AppStorage、导航、集合或用户数据。原有SharedSurface/按钮不自动增加橄榄油，产品在需要的同类模块切换处显式采用。

## 时序与几何契约

- 内容隐藏25ms；锚点就绪后主体240ms，曲线 `(0.12,0.24,0.82,0.62)`。
- 主体开始后50ms发出内容显现事件，内容用10ms淡入；不等待轮廓结束。
- 形状进度前4%先融合；拉伸0.64、收颈从0.36、间距从0.40、双卡连接在0.97完成分离。这些是曲线插值后的形状进度，不能直接当作墙钟时间百分比。
- 缺失锚点120ms兜底落定目标并解锁；减少动态效果不启用共享轮廓变形，以100ms淡变切换内容。
- 双卡根部与颈部共同收缩到零面积；群组、轮盘及模块连接公式对应iOS实现。所有连接片保持与主体一致的填充方向，重叠处不挖空；iOS对应使用闭合轮廓并集。

每个宿主创建一个session。回调收到 `hide/shape/reveal/reduced` 时，在 `getUIContext().animateTo(oliveOilAnimation(state), ...)` 内更新形状progress和内容透明度；`measure`事件先解析并缓存同一坐标系的可见源和目的锚点，再调用 `startSurface()`。不要把屏幕外模块加入源组，不在动画中重测并替换快照。后续 `idle` 清除共享覆盖层，恢复真实模块表面。没有锚点时让兜底执行，不伪造产品几何。

把共享轮廓放在内容背景层，运行时隐藏真实表面但保留其几何和文字层；文字显隐读取 `contentVisible`，业务内容选择读取 `contentExpanded`。这些参数与轮廓progress分开。固定工具栏/图标继续挂载，不能随目的页面整体重建。禁止在shape动画中触发评分、计时、存储或业务完成。

`OliveGeometry`声明 `sources/destinations/axis/mode/radius`。group支持任意横/纵组，cluster目的地为上下两卡，radial目的地第一个矩形为hub，ligament目的地为相邻两模块。坐标以宿主传入的viewport逻辑空间为准。Path命令是px，适配器将viewPort明确声明为px，再映射到实际宽高，避免高密度屏缩小。不是将vp值直接混入物理路径。

页面离开、进入后台或Reduce Motion偏好改变时调用 `settle()`；真正销毁时 `dispose()`。旧回调有代次检查；每个session只能归一个宿主。局部切换可传 `navigation=false` 允许重新定向，原生属性动画从当前可视状态继续；导航默认拒绝重复点击。

## 与iOS统一的范围

iOS实现已统一进入 `JideFoundation/Sources/JideFoundation/OliveOil`；新应用只需 `import JideFoundation`。旧JideMorphTransition目录只作兼容重导出。鸿蒙在HAR内实现相应轮廓和生命周期，未复用SwiftUI运行时。

共同部分是核心轮廓、阶段、曲线、时间和打断边界。SwiftUI连续圆角与鸿蒙三次圆角、平台玻璃材质、光照和符号替换保留平台差异，不承诺逐像素相同。共享轮廓色由宿主提供；若需要玻璃，实际表面与共享覆盖层应采用一致颜色和宿主材质，不能对每个连接子轮廓重复加模糊或投影。

## 验证

`npm test`运行真实时序/取消/重入/减少动态效果测试，以及从iOS XCTest导出的66帧Path.contains参考，每帧1600点，共105600采样点。六类轮廓逐帧比较，每帧最多允许2%的连续圆角边缘差异；该阈值不等同像素一致度或帧率证明。参考来源是iOS基础库 `OliveParityTests.swift`，原始JSON存于 `tests/fixtures/olive-ios-reference.json`。

`npm run check`检查依赖、来源和链接；`npm run build:harmony`实际消费全部公共导出并构建HAR/独立样例。通过后同步登记消费者。设备验证使用独立bundle `com.jide.foundation.smoke`；普通播放通过原生可动画属性逐帧重算，手动Slider只用于检查形状，不作为实际播放的替代证据。

本轮不把基础库交付、消费者依赖同步或样例跑通表述为鸿蒙JideCards所有产品场景已完成接入。其页面锚点、工具栏、评分、轮盘和业务生命周期需要在对应产品任务中逐处验收。
