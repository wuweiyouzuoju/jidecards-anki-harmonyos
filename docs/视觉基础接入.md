# 系列视觉基础接入

2026-10-29，HAR 0.2.1。视觉参照为本机 iOS JideCards `UI/Theme/JideChrome.swift`，来源哈希见 [provenance.json](../provenance.json)。实现为 ArkUI；不是 UIKit/SwiftUI 材质或油膜转场的像素复刻。

## 正式入口

| 入口 | 职责 |
| --- | --- |
| `SharedPageBackground` | 静态渐变与径向氛围；无计时器，不拦截触摸 |
| `SharedSurface` | 统一表面、描边、薄材质与柔和投影；不添加padding、布局或动画 |
| `SharedActionButton` | 原生Button、至少52vp的总高度、长文案增长、可选副标题、忙碌/禁用守卫与按压 |
| `VisualTokens` | 新档16vp页面留白、22vp卡片圆角、16vp内边距、12vp组间距、560vp内容宽度上限 |
| `visualPalette` / `VisualPalette` | 深浅默认语义色及产品完整覆盖入口，不持有AppStorage或产品主题状态 |
| `surfaceAppearance` / `visualPressScale` | 可执行纯样式规则；减少透明度清除模糊与投影，减少动态效果取消按压缩放 |

旧 `UiTokens`、`SharedIconButton` 和各产品适配器维持原契约。候选 `ActionButton` / `DialogSurface` 仍不因新增组件就成为正式公共API。通用危险确认仍使用产品已有语义，不以学习按钮替代。

## 接入方式

```typescript
import { SharedPageBackground, SharedSurface, SharedActionButton,
  VisualTokens, visualPalette } from 'jide_foundation';
```

页面在底层放 `SharedPageBackground({ isDark: this.dark })`；正文自行处理安全区、滚动、宽度和 `VisualTokens.pageInset`。卡片在已有Column/Row的外壳设置一次padding，然后 `.attributeModifier(new SharedSurface(this.dark))`。纯扁平表面用 `new SharedSurface(this.dark, 'flat')`；禁用透明度用第三参数true。最后两个参数是圆角和完整语义色。

学习动作使用 `SharedActionButton({ label: '开始学习', isDark: this.dark, onAction: ... })`，可传 `subtitle`、`busy`、`isInteractive`、`material`、`motionStyle`、`reduceMotion`、`reduceTransparency`。不增加点击延迟。单行至少52vp，双行与大字号可以增长；父级不要再叠固定高度或垂直padding。

产品已有主题时向背景和按钮传同一 `palette`，向表面传相同色表；颜色格式为六位RGB，透明度由公共实现转ARGB。设置 `isDark` 显式控制模糊模式，避免应用主题与系统主题相反时材质错误。偏好由产品读取后传入；组件不声称已经自动订阅系统无障碍设置。系统栏由窗口宿主维护，样例给出了可执行的宿主适配。

缩放和透明度由原生属性驱动，页面不另设onTouch抢占手势。同一个表面切回扁平或减少透明度时显式清除模糊和投影。橄榄油由独立公共动效模块提供，见[橄榄油](橄榄油.md)；形变导航、菜单锚点、弹窗预算与业务关闭均不由表面修饰器承担。

## 运行与验证

[VisualShowcase.ets](../examples/VisualShowcase.ets)为独立应用样例，合成数据不写入产品。`npm run build:harmony`编译样例和原有检查页，并输出HAR；最新夹具路径在 `.local/harmony-build.json`。在该夹具目录使用 `devecocli run --skip-build --device <模拟器名>`，仅运行独立bundle `com.jide.foundation.smoke`。

执行 `npm test`、`npm run check`、`npm run build:harmony`；再 `npm run sync:consumers` 与 `npm run check:consumers`。设备检查深浅色、点击、禁用、减少透明度与扁平往返；大字号、长英文、宽屏、原生窗口和读屏仍应按各产品实际宿主验收。样例验收不能代替全系列页面接入。

## 0.2.3：真实透射与层级

内容和操作表面采用分开的alpha：content浅色0.48/深色0.62，control浅色0.14/深色0.30，按钮比普通模块更通透。`SharedSurface`最后一个可选参数 `role` 为content/control；公共学习按钮显式采用control。背景仅由外壳绘制一次，页面宿主不要用不透明底色遮住它。

材质使用背景模糊、透射底、高光和细描边，不使用不透明底与系统白色材质相叠加；扁平、隐藏和减少透明度会清除背景模糊及高光，文字和图标不参与表面透明度计算。新增visible参数只负责清除绘制，不拥有任何形变状态。

闪卡已登记为第三个正式消费者；其产品按最新用户要求取消橄榄油接入，公共库保留独立能力不等于该产品启用。现有页面按产品契约使用正常导航和操作。

0.2.4：深色玻璃降低白色高光与边缘亮度，阴影半径10、垂直偏移3；普通内容填充0.68，控件0.24。消费应用可以默认 flat，并通过设置显式采用 glass。flat 始终清除模糊、渐变和阴影。
