# 弹窗折射玻璃

来源：2026-10-30 用户确认的 Jidecards 首页更多菜单版本。实现已提炼进公共 HAR；Jidecards通过薄适配消费公共实现，公共菜单、对话框、选择器、箭头工具弹层及旧自绘面板已统一接入；产品覆盖、系统例外和实际设备验证范围见Jidecards弹窗玻璃接入。

## 唯一实现与观感

- `SharedGlassBackdrop`：面板背后的真实背景采样、整块5.5vp轻度模糊和连续折射。文字、图标放在上层，保持清晰。保留背景色彩，避免用大面积白色填充制造磨砂。
- `src/core/GlassOptics.ts`：圆角距离场和纹理网格。36vp过渡带、位移上限10vp；轮廓处位移归零，采样不回折，防止背景细线断开。不要在产品复制调参或另画一圈清晰边缘。
- 适用于玻璃材质、API23+的明暗自绘弹窗，明暗共用采样与折射，深色使用中性深色调色层。API21–22/采集失败沿用产品已有材质；系统拥有的授权弹窗保持系统渲染。

## 接入契约

1. 页面正文及真实底色组成带唯一 `id` 的采样源；弹窗、遮罩及触发后出现的覆盖层必须在采样源外，避免自采样。多窗口独立会话，同一源共享最长边不超过512物理像素、且不超过半分辨率的背景。
2. 页面可见时调用 `warmSharedGlassSource(ui, sourceId, true, captureAllowed)`，离开时传false。`captureAllowed`由产品读取真实材质与前后台状态，关闭玻璃或进入后台时返回false；基础库不读取产品AppStorage。
3. 在弹窗容器中直接调用 `SharedGlassBackdrop({ source, region, radius, active, dark, role, captureAllowed, onReady })`，作为内容下面的绝对定位子层；`region`为面板实测的**窗口坐标和尺寸，单位vp**，子层宽高与面板相同。不能把初始零尺寸经按值外部Builder固定住，不能用原生background(builder)晚建背景。
4. 玻璃与文字属于**同一展开容器、同一动画所有者**。完成布局和首次纹理绘制的onReady后一起展开；准备阶段使用可绘制的极低透明度（参考0.01），完全opacity(0)可能跳过首次绘制。参考首页当前AnchoredMenu的准备流程；等待真实纹理绘制就绪，不以超时锁定或切换材质。不得增加第二套进入动画。
5. `active`负责玻璃模式及前后台条件，`dark`显式传入，`radius`匹配实际轮廓；完整菜单由SharedAnchoredMenu消费产品提供的实测锚点、安全区、键盘和关闭回调；业务层级与焦点仍归产品。带箭头或异形弹窗须由其公共宿主统一提供相同轮廓，不能只贴矩形纹理冒充完成。

API和可编译用法见 [GlassShowcase](../examples/GlassShowcase.ets)。接入产品前先构建HAR、仅同步目标消费者，再构建产品，详见[公共HAR接入](公共HAR接入.md)。

## 验收

查全菜单、对话框、选择器、确认/输入/加载提示及底部面板的公共宿主，按宿主接入，记录实际覆盖与系统弹窗例外。实看明暗主题、窄宽窗口及叠层；连续抓帧检查首个可见面板已含玻璃，稳定展开后无换图；背景细线穿过圆角连续、原生字清晰、关闭后释放采样。不要仅凭import或编译成功认定视觉接通。

本次沿用原产品已确认的视觉参数与设备证据；公共提炼另做纯光学回归和HAR/HAP编译验证，未宣称所有产品或全部弹窗已迁移。

## iPhone17参考与深色一致性

2026-10-30实看iPhone17的原生牌组上下文菜单，作为雾面底色、细边和动作分组的参考；鸿蒙在此基础上增加自身连续折射。`role: 'menu'`保留已确认的轻模糊透射；`role: 'dialog'`使用同样纹理和光学，再叠中性雾面底色压住背景字。深色不得跳过纹理或套浅色白色填充。宿主必须按同一圆角clip整个背景与内容，避免绝对定位玻璃层超出实测面板。

深色按钮和内容模块共用surfaceAppearance的0.8vp、#22FFFFFF细边，弹窗同样使用低对比边界；不要在产品为模块重新硬写较亮边框。明暗主题、切换、细线连续与第一帧展开必须分别验收，编译成功不代表这些视觉检查已做完。


箭头轮廓接入：`contourPath`可传宿主实际使用的物理像素M/L/Q/C/Z路径，基础库从同一轮廓计算距离场；宿主仍以该路径clip整个面板。省略时保持原圆角矩形参数。网格只在尺寸、密度、圆角或路径变化时重建，窗口平移和重复布局只更新采样原点；轮廓距离场使用标量计算，避免生成最近点临时对象。产品不能将背景的实测尺寸反向作为正文固有尺寸；绝对背景/描边须退出布局测量，防止逐帧撑大。

2026-10-30线状伪影修正：距离场最近边在圆角内侧的中轴线上切换，微小差分法向再归一化会把采样方向突变放大，造成纹理三角形回折及斜线。GlassOptics改为在36vp过渡带上求平均梯度并保留梯度自然衰减；轮廓与带内缘仍归零，平直边缘保留既有强度、10vp位移上限和整块5.5vp轻模糊。圆角矩形多尺寸/圆角/密度回归检查每个纹理三角形方向为正；产品箭头轮廓检查同一不变量。不得以增大模糊、加实底或关闭折射掩盖接缝。

2026-10-30 唯一导航背景：宿主可以给 SharedGlassBackdrop.backgroundSource 与 warmSharedGlassSource 第5参传同一个真实背景节点ID。会话先采透明正文，再按两节点窗口位置及像素比例原生合成该背景；临时输入在finally释放，背景不可用时走原降级，不发布透明黑底。未传参的消费者保持原采样路径。全屏覆盖层可用role=background显示该源原始帧：无折射、无模糊、无额外色层；它不创建主题或动画。普通menu/dialog的纹理和光学参数不改。glass-capture.test.mjs直接执行合成与绘制，覆盖坐标/缩放/顺序/释放/失败/默认兼容及原始帧和折射帧分离。

闪卡首页材质推荐按用户验收要求单独示范准备等待：默认普通宿主250ms规则不变，推荐宿主在产品层指定800ms最短示范与1200ms准备期限，150ms后出现缓冲，纹理/正文仍由同一容器一起展开。此为用户明确要求的示范，不修改公共光学参数或其他消费者。

上述闪卡800ms最短时长已在用户验收后移除：正式推荐准备好即展开，150ms后按需显示缓冲，仍失败时在产品指定1200ms期限降级；其他宿主保持默认250ms。公共HAR无需更改。

2026-10-31：平板展开牌组追踪发现整页半分辨率模糊单次约45—51ms。采样分辨率改由GlassCapture.glassCaptureScale按最长边512像素限制；背景与正文使用同一scale，模糊半径仍由最终PixelMap实际比例换算，采样坐标不变。原生文字、图标及玻璃轮廓不降分辨率。产品需分别验证处理耗时和观感，不以包构建代替性能验收。


## 材质融合 SharedGlassFusion（2026-10-31）

基础库提供独立过渡层`SharedGlassFusion`，复用本文件的背景会话与轻模糊纹理；`src/core/GlassFusion.ts`持有解析圆角距离场、平滑并集和动画中256基础网格单元的裁切三角化（静止端点使用最多64×64连续规则网格）。它不是两个玻璃视图的交叉淡化，也不复用多段路径解析器（该解析器仅处理首段Z，不能正确表达融合形状）。每帧只推进几何，融合期间暂停该源的新采样/模糊；结束解除暂停。小圆按钮使用当前轮廓包围盒分配网格预算，避免长行程空白降低小轮廓精度。

参数：`source`/`backgroundSource`沿用原采样源；`region`是融合层包围盒（窗口vp）；`geometry.source/target`均为窗口vp的`{x,y,width,height,radius}`。两轮廓和中间连接必须位于region内，外留至少min(source.width,source.height)*0.17+1vp；组件自身必须定位到region对应位置且不能被最终弹窗clip。几何由宿主实测提供，region/geometry变化时在同一材质层重建几何缓存，保持当前进度，不重播入场；不能以输出纹理尺寸逐帧反写正文测量。当前只支持圆角矩形/圆形到圆角矩形，尖角异形维持既有动效，不冒充全部轮廓已融合。

`expanded`可在运行中反向，接续当前进度；`active`必须转发前后台与页面可见性；`reducedMotion`显式传入；`captureAllowed`仍由宿主提供。准备真实纹理后使用UIContext.postFrameCallback，时长限制100—500ms、默认280ms；500ms未准备好回调not_ready，宿主显示已准备的普通面板。运行中不因计算超预算跳终态；超预算只记录为实验失败并继续优化。onComplete(reason)只通知当前阶段，宿主负责显示最终内容/移除过渡层；退出、后台和销毁停止后续帧，保留已有业务关闭守卫。无API23或无有效几何回调unavailable，未引入平台特权或产品全局存储。

公共日志GlassFusion记录几何CPU均值/峰值与帧数，不等价于GPU耗时、掉帧率或端到端延迟。`tests/glass-fusion.test.mjs`覆盖精确端点、网格预算/有限数值/不回折、边界零位移、反向、销毁和降级；基准报告host几何耗时，不能用它声称真机不卡顿。目标消费入口先为闪卡首页更多/新建；其他弹窗与原生窗口仍沿用原有宿主，未自动更改所有消费者。

菜单触发按钮可给SharedPressFeedback第四参传1，并令第三参缩放回调返回1，保持按下/松手时的亮度和几何稳定；默认0.72保留普通按钮反馈。融合完成后推荐保留同一个SharedGlassFusion作为最终材质层，文字/交互在其上层呈现，避免再换回另一套玻璃底色而出现二次闪变。产品需要让最终内容壳变为透明，并保持它首次持有的采样引用直到真正销毁，不随surfaceVisible切换丢失释放责任。


首轮真机实测曾连续触发frame_budget，原1024单元不能满足目标平板预算；后续收敛为256单元并缓存共享顶点梯度，不能引用旧host基准声称设备流畅。过渡组件的调用方自定义组件外壳也须显式HitTestMode.None，内部NodeContainer设置不代表外部包装节点自动透传。设备日志使用字符串格式记录小数，避免hilog浮点格式错位。


### 当前实验策略（覆盖前述性能跳终态规则）

长期任务及可重复命令见[玻璃融合实验](玻璃融合实验.md)。当前已移除连续超预算跳终态；完整播放与性能指标独立验收。网格预算在同一次转场固定，顶点/交点/输出缓冲复用并共享索引，避免重复三角形采样与宽高比变化导致拓扑跳变；渲染节点复用纹理坐标、画笔和边线路径。meshBudget仅供独立实验比较，正式默认256且不运行中切换。性能报告保留失败与未完整播放；GPU和连续视觉仍需单独测量。


2026-10-31公共宿主扩展：SharedGlassFusion增加region/geometry/dark观察与animateEntrance。动态正文、键盘和窗口变化更新同一层；animateEntrance=false用于已完成弹层在后台恢复/材质重建时直接恢复终态，仍等真实纹理后通知。产品GlassPanel普通圆角表面和全部普通AnchoredMenu默认复用，尖角与全高侧栏分别保留精确路径和侧滑，opaque及系统窗口保留其业务约束。用户取消的反向关闭仍须由外部宿主持有expanded与移除时机；原生窗口被平台移除不能靠子组件aboutToDisappear补做反向动画。

按钮前景层（0.2.13修正，取代0.2.10）：背景纹理为低分辨率，不能重放整个触发按钮并覆盖原生边界。生产SharedGlassFusion在过渡阶段将原按钮实测圆角区域排除出光学网格绘制；同次sharp快照仅重放向内2vp的内容区域，按钮轮廓与抗锯齿继续由原生按钮拥有。终态移除该裁切和内容重放，保留完整目标面板。几何统一调用glassPopupTriggerRect并传入控件实际圆角；不得用16vp默认值替代44vp圆形工具按钮的22vp圆角。GLASS_MENU_ENTER_MS=160为系列菜单展开时长，产品SurfaceTransition引用它；对话框仍可显式提供自身语义时长。GPU实验未启用这些额外绘制，不声称实验路径等价。


深色轮廓可选接入（0.2.11）：SharedGlassFusion的contourStrokeWidth/contourStrokeColor默认0与透明，不改变未接入消费者。生产光学节点在完整网格及色层之后、按钮前景之前，沿mesh.edge成对线段绘制同一帧轮廓；不连接相邻线段之间的空隙、不用固定圆角矩形替代球形。宽度按vp乘当前密度；关闭时宽度传0，下一帧不再绘制轮廓。产品拥有颜色、明暗与是否显示，jidecards统一深色0.8vp/#22FFFFFF。GPU实验没有新增此描边，不声明等价；仅同步jidecards消费者。


连续外框与终态网格（0.2.12）：修正完全位于轮廓内的三角形漏报直边，不能将四角裁切段误当完整周长。静止端点以规则网格消除自适应T接点插值接缝，clipRect传递真实圆角矩形给生产绘制者，原生裁切保持精确外缘；终态描边为完整向内偏移半线宽的圆角矩形。动画阶段维持原球形和折射及单一播放所有者；中段仍使用成对轮廓线段。tests/glass-fusion验证完整周长、共享内部边及边界误差，产品直接绘制回归验证整框与绘制顺序。此条取代0.2.11“所有状态都用edge线段描边”的实现，3.8.31平板四角线与上角接缝为失败证据。


复合菜单生命周期：子层返回不能触发主菜单的expanded=false；根收起即使渲染失败也必须释放承接层。主/侧/覆盖子菜单使用同一页源，不递归截图父菜单，以免白底、主题选中块和文字反复模糊并造成颜色不一致。覆盖位置仍由产品原布局拥有。页面内容GlassSource与菜单必须为兄弟层；菜单不能进入自身采样源。详情更多不得给整页额外加模糊蒙层，原生触发按钮边界应与主页菜单一致。

2026-11-04：完整菜单、指向轮廓、弹层准备与行绘制已提取，当前唯一入口和产品适配边界见[完整菜单接入](完整菜单接入.md)。

## 透镜与反光

圆角和异形表面、融合动画使用统一2%内部透镜放大，轮廓处位移为零，沿原距离场平滑接入。共享RenderNode绘制0.85vp方向性镜面反光，静态路径和渐变画笔按几何缓存，融合反光跟随当帧边界。根背景原图副本保持两片三角形与原始采样。当前实现采用固定斜向光源；验证应分别观察浅深色、静态轮廓和融合中间帧。

静态反光路径、渐变画笔及纹理坐标按几何缓存，融合路径清空后复用同一Path。几何不变的重绘直接复用转换后的纹理坐标，平移和变形使缓存失效。共享玻璃弹层就绪后使用16vp低不透明度投影及5vp垂直偏移。性能验证区分Node算法成本、ArkUI绘制日志及真实硬件帧率。
