# 记得闪卡 v2.3.3 官方公告设计

> 归档状态：这是一次性历史设计/执行记录，不是当前路线图、待办列表或操作手册。未勾选项不表示仍未实现；当前事实请查阅 [文档导航](../../README.md)、[开发状态](../../DEVELOPMENT_PLAN.md)、[当前架构](../../architecture.md) 和实际源码/测试。


## 目标

用云端官方公告取代旧的版本更新开屏弹窗，向从应用市场 2.0.0 升级到 2.3.3 的用户介绍能直接体验到的主要变化。语气轻松、信息明确，不罗列开发实现细节。

## 展示方式

- 继续使用现有官方公告弹窗。它已经与旧开屏弹窗采用相同的全屏磨砂背景、居中圆角卡片和淡入缩放动画。
- 标题为“记得闪卡 v2.3.3 更新”。
- 正文沿用旧弹窗的 `【新增】`、`【优化】`、`【修复】` 行式格式。
- 底部仅保留“我知道了”；不能通过返回键或点击遮罩关闭。确认后同一公告不再显示。
- 旧欢迎弹窗继续保持静默，不与官方公告连续出现。

## 中文正文

【新增】首次加入云端牌组下载。进入软件即可选择并下载 6 套牌组：CET 四六级词汇、高考英语词汇、中考英语词汇、AI 机器学习、AI 计算机专业工具名词术语和中国法律专业版；下载完成后会自动导入，不用再手动找文件。更多、更全的牌组可加入官方 QQ 群 726837065 获取。

【新增】新增官方公告。以后重要更新和通知会在首页及时送达，点击“我知道了”后，同一条公告不会重复打扰。

【新增】云端牌组会显示卡片数量、版本和文件大小，支持多选、下载进度和逐个导入；失败项目可以重试，已经成功导入的不会重复处理。

【优化】AnkiWeb 同步页新增账号说明和免费注册链接，第一次使用同步更容易上手。

【修复】修复部分图片在创建图片遮罩卡片时无法读取或格式识别失败的问题。
