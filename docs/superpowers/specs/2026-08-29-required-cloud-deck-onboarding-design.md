# 一次性强制云端牌组引导设计

> 归档状态：这是一次性历史设计/执行记录，不是当前路线图、待办列表或操作手册。未勾选项不表示仍未实现；当前事实请查阅 [文档导航](../../README.md)、[开发状态](../../DEVELOPMENT_PLAN.md)、[当前架构](../../architecture.md) 和实际源码/测试。


## 目标

云端牌组只在一次性首次引导中提供。新安装用户，以及首次升级到包含该引导版本的老用户，打开应用后必须至少成功导入一个云端牌组，才能进入首页。完成后不再显示该引导，也不在“新建牌组 → 导入牌组”中保留软件云端入口。

## 界面与文案

弹窗继续使用现有磨砂玻璃遮罩、卡片、圆角和转场。遮罩点击、系统返回和关闭按钮均不能绕过引导，不再显示“暂时跳过”。顶部小字使用：

> 首次进入可自由选择所需牌组，至少选择 1 个，下载后将自动导入。本次选择机会仅有一次，请按需选择。更多最新牌组请加入官方 QQ 群：726837065。

牌组列表展示名称、说明、卡片数量、版本和文件大小。卡片数量来自托管 JSON，不在手机端打开 APKG 统计。目录包含以下六个公开牌组：

| 牌组 | 卡片数量 |
| --- | ---: |
| CET 四六级词汇 | 14,311 |
| 中考英语词汇 | 3,305 |
| AI 机器学习 | 1,450 |
| AI 计算机专业工具名词术语 | 1 |
| 中国法律专业版 | 2,500 |
| 高考英语词汇 | 8,453 |

未选择牌组时下载按钮禁用。成功导入至少一个牌组后显示“进入软件”；选择多个但部分失败时，用户可以重试失败项，也可以进入首页。全部失败时不能进入。

## 状态与数据流

1. 使用新的强制引导偏好键，使新安装用户和从旧版升级的用户都进入一次该流程。
2. 首页启动时先读取该键；未完成时只展示强制云端牌组弹窗，不展示欢迎弹窗，也不允许进入其他首页操作。
3. 用户至少选择一个公开牌组后，应用串行下载完整 APKG，并复用现有导入服务自动导入。
4. 下载开始时不写完成标记。只有至少一个牌组成功导入、用户点击“进入软件”时，才持久化完成标记并关闭弹窗。
5. 网络、目录或全部导入失败时保留弹窗和选择状态，提供重试；不得写完成标记。
6. 完成标记写入失败时不关闭强制引导，避免下一次启动产生语义不一致。
7. 完成后，后续启动不再展示云端牌组；“新建牌组 → 导入牌组”直接打开本地 APKG 选择器。

完成标记使用固定的引导代际键，不直接使用应用版本号。首次升级到本功能版本的旧用户因没有新键而进入一次引导；完成后正常覆盖升级到任何后续版本都沿用该键，不重复展示。卸载重装或清除应用数据会移除本地偏好，因此按新用户处理。未来目录新增牌组也不会重新触发引导，用户通过官方 QQ 群获取后走本地导入。

下载先写入 `.part` 临时文件，只有大小和 ZIP 签名校验通过后才改名为 `.apkg` 并交给导入服务。普通失败、暂停或无进度超时立即删除临时文件；若进程被系统直接终止，下次加载强制引导时清理私有 `cloud-decks` 目录内残留的 `.part` 和 `.apkg` 文件，再从头下载。中断或残留清理均不得写完成标记。

## 托管目录

目录协议新增可选的正整数 `cardCount`。六个现有条目都提供该字段；客户端对旧目录缺少此字段时仍可加载，仅省略卡片数量。新增“高考英语词汇”条目，版本为 `1.0.0`，使用用户提供的 123 云盘 HTTPS 直链，文件大小为 `184166749` 字节。

本地 `hosting/cloud-decks.json` 是发布源；软件代码完成并验证后，需要将更新后的 JSON 上传覆盖 123 云盘同名文件，客户端才会获取六牌组目录和卡片数量。

## 删除与重新获取

本次不实现按牌组记录“已领取”或限制重复下载。一次性引导完成后软件内不再提供云端入口；用户若删除全部或部分牌组，可通过官方 QQ 群获取最新牌组文件，再走本地导入。牌组删除后的媒体自动清理不属于本次改动。

## 验证

- 目录模型测试：接受合法 `cardCount`，过滤非法值，兼容缺省值；六个托管条目的名称、大小和卡片数准确。
- 界面契约测试：显示优化后的引导文案和卡片数量；无跳过/关闭入口；零选择时不可下载。
- 首页流程测试：新安装与首次升级用户触发；后续覆盖升级不重复触发；下载开始或中断不完成引导；零成功不能进入；至少一项成功后点击进入才持久化。
- 下载生命周期测试：传输只写 `.part`；校验成功后改名；失败路径和下次引导清理 `.part`/`.apkg` 残留。
- 入口测试：“导入牌组”直接走本地选择器，软件云端入口不再可达。
- 构建与模拟器回归：首次启动、部分失败重试、成功进入、重启不再弹出，以及本地导入路径。
