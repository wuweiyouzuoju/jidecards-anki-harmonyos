# 一次性设计与执行记录（归档）

本目录保留 2026 年 8 月功能开发时生成的 plan/spec，目的是追溯当时的需求、取舍
和验证过程。它们不是当前路线图、当前待办列表或操作手册。

特别注意：

- 许多 implementation plan 在功能完成后没有回填 checkbox；未勾选不表示仍未实现。
- 部分文件描述 2.0.0、2.3.3 或未发布的 3.0.0，版本和 UI 裁定可能已经被后续改动覆盖。
- 个别方案已明确作废；其错误根因和验证方式只作为审计记录保留。
- 当前事实应查阅 [文档导航](../README.md)、[开发状态](../DEVELOPMENT_PLAN.md)、
  [当前架构](../architecture.md) 和实际源码/测试。

新增功能不要继续向本目录堆积长期状态。一次性设计可以保留，但完成后应把仍然
有效的结论收敛到当前文档，并在历史文件顶部标明归档状态。文件正文中的步骤、
命令、技能要求和决策路径全部是历史记录，不能约束当前编程 Agent；当前决策只能
写入受版本控制的 [docs/decisions/](../decisions/README.md)。
