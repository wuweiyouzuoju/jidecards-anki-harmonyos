# 记得闪卡 26.11.03.1 源码更新说明

日期：2026-11-02。源码版本 26.11.03.1，构建编号 3140；应用市场已确认版本仍为 3.8.1。以下为源码改进，不代表应用市场已经发布。

- 自定义主题色增加浅色、深色各自的明暗适配强度，可预览原始颜色与实际强调色，保存或取消预览。
- 统一宽屏、窄屏下通过更多按钮或长按打开牌组设置的效果：背景保留阴影并增加强模糊，菜单和牌组预览保持清晰。
- 卡片脚本异常改为独立的详情入口，复用已有弹窗查看错误信息，避免技术堆栈直接占据卡片正文。
- 补充半屏、悬浮和全屏切换时的内容布局适配；复查玻璃与扁平材质、主题色切换，以及八个首页摘要分页，未复现旧版白底残留，摘要与牌组列表左右边界保持对齐。
- 源码展示版本改用日期加递增序号：日期取发布操作当日的次日，最后一段为常规递增序号；本次为 26.11.03.1。
- 完善字段展开窗口：保留当前字段草稿和编辑模式，补齐输入边界，移除展开窗口中重复的模式按钮。
- 统一页面玻璃背景：设置、学习、编辑、浏览、牌组选项和预览外层随材质切换，玻璃时透出根背景，扁平时保留原底色。
- 提高字段模式按钮文字对比度，依据实际主题实底选择黑色或白色文字。
- 首页入门按 Anki 经验分流，新用户增加闪卡、准备第一副牌组与日常复习教学；完成选择并保存后才进入导入、新建或同步。
- 完善浏览多选完整计数、牌组快捷操作及自定义学习数值记忆。

验证：83 项相关应用测试、12 项版本工具测试与签名构建通过；在手机和宽屏模拟器检查主题切换及窗口行为。此记录不替代所有实体设备验收。公开 HAP 下载仍以已存在的 Release 附件为准。
