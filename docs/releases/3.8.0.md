# 记得闪卡 3.8.0 更新说明

更新日期：2026-10-30。源码版本 3.8.0，构建编号 3101；版本来源为 [AppScope/app.json5](../../AppScope/app.json5)。本页以 3.5.4 为上一版整理更新，不以未提交改动或 GitHub 旧基线代替版本差异。

## 界面与使用体验

- 重整原生界面：统一首页、牌组详情、统计、设置的卡片表面、圆角、边框及按钮，统一菜单、弹窗、搜索与选择控件。
- 完善玻璃与扁平材质：优化深浅色对比度和按压反馈，共享幻彩背景与玻璃采样，修正全屏预览背景；默认扁平，通过一次推荐自主选择玻璃。
- 完善界面衔接动效：首页与牌组详情工具栏、学习答题操作区、浏览多选操作区及编辑轮盘的状态切换采用共同的动效和恢复机制。
- 调整首页牌组布局与操作：双列布局按完整顶级牌组子树分配到较短一列，减少成对排版留白；完善宽度建议、牌组菜单、摘要与详情展示。
- 完善制卡字段布局：调整模式切换、标签、草稿预览与字段固定入口，统一轮盘工具的图标和文字呈现。
- 新增编辑轮盘自动展开设置：分别控制进入编辑与键盘弹出时是否展开，并保存偏好。
- 改进绘图文字调整：边缘控制点分别拉伸宽度或高度，角点保持等比缩放；同步调整选择框、控制点与工具布局。
- 完善多语言与地区体验：提供 12 种语言与地区选项，统一日期和数字格式，调整长文案、大字体与窄屏布局。
- 恢复幻彩兑换成功展示与粒子动效；关闭动画或进入后台时保留静态结果。
- 同步 JIDE 的设置目录、编辑轮盘偏好和界面状态认知，沿用原有操作确认与保存边界。
