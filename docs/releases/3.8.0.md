# 记得闪卡 3.8.0 更新说明

更新日期：2026-10-30。源码版本 3.8.0，构建编号 3101；唯一版本来源为 [AppScope/app.json5](../../AppScope/app.json5)。

- 新安装默认使用玻璃材质，已有扁平用户可通过一次推荐选择切换或保持当前；设置去除“扁平”的默认标记。
- 首页与其他页面共用导航根部唯一幻彩背景和动画时钟；透明正文的玻璃采样合成同一真实背景，全屏卡片预览显示原始背景帧并隔离下层控件。
- 恢复首次成功兑换幻彩后的礼物与粒子动效，修复兑换结果状态传递；动画关闭或进入后台时显示静态结果。
- 推荐按钮继续复用公共组件，区分主次操作，等待保存时在实际选择的按钮显示状态并阻止重复提交。
- 白板添加/替换图片复用已有图标按钮。

延续[3.5.19 源码说明](3.5.19.md)中的既有功能。此次版本调整不表示已上传或上架。签名构建、设备安装与具体交互验证范围分别记录，真实首次成功兑换动效尚未使用真实兑换码进行设备验收。
