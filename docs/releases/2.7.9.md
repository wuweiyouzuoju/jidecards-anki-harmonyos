# 记得闪卡 2.7.9 更新说明

2.7.9 是在 2.7.0 基础上的累积更新。版本元数据为 `versionName: 2.7.9`、`versionCode: 2790`。

## 学习与同步

- 完善学习会话生命周期：评分、撤销、埋藏、暂停、完成页、当前卡片编辑和内容刷新之间的状态衔接更稳定。
- 增加自动前进、显示答案、自动操作、等待音频、答题计时器、显示答案后停止计时、答案重播跳过问题等牌组选项的实际执行链路。
- 增加评分触感反馈，并支持在设置中关闭；音频和 TTS 等待真实播放队列完成后再继续。
- 自动同步改为由首页根宿主统一调度，学习、编辑、导入、弹窗和集合写入之间有明确的占用边界；支持同步取消、手动同步排队、失败重试和冲突详情。
- 手动同步返回首页后会继续唤醒；等待状态显示实际原因，已有同步任务时直接打开任务详情，不覆盖当前进度。

## 首页、牌组与数据管理

- 增加首页“记得闪卡”速览，可介绍闪卡、APKG 导入、Agent 制卡/改卡和评分流程，并可从“更多”重新打开。
- 增加云端公开牌组目录、首次引导、下载配额和串行导入；导入失败的单个牌组不会阻断后续任务。
- 支持系统通过 FileOpen 直接打开 `.apkg`，冷启动和热启动都能进入现有导入流程；学习、编辑或同步占用时会排队并对重复 URI 去重。
- 删除牌组后可单独检查本次新增的未引用媒体，并将其移入已有回收站流程；不会直接永久删除或清理历史闲置文件。
- 牌组支持隐藏、恢复、颜色条、别名、背景图片和层级顺序管理；牌组选项增加当前牌组、共用设置和全局设置的作用范围说明。

## 浏览、统计与设置

- 浏览页增加 Cards/Notes 模式、状态筛选和排序入口，修正暂停标记、分页、预览切换及批量操作的过期响应问题。
- 批量删除、改牌组、标志、暂停/恢复、到期、重排、笔记类型和查找替换共享操作控制器，避免旧操作覆盖新选择。
- 统计页完善全局牌组范围、时间范围、分位数、年历边界和 FSRS 展示；首页统计与桌面服务卡片共用快照。
- 设置页整理为常规、外观、控制、同步、数据等分类，增加简洁版/实验版模式；主题、卡片字号、背景动效、评分触感、自定义同步端点和应用指纹/兑换入口统一管理。
- 所有原生选择框统一字体、尺寸、圆角和选中态，修复切换选择后字体或圆角恢复系统默认的问题；牌组选项帮助图标紧跟对应文字。

## 卡片渲染与媒体

- 学习页和浏览预览共用模板样式、脚本、MathJax、mhchem、MathML、jQuery 和本地媒体响应链路。
- 修复模板 CSS 与脚本边界、导入数学/化学内容离线显示，以及本地媒体 `Range`、`206`、`416`、`HEAD` 请求和短读处理。
- 学习页与预览页共用音频生命周期，降低旧卡片异步渲染或音频回调覆盖当前卡片的风险。

## Agent 与发布边界

- Agent 增加会话历史、流式草稿、工具过程、澄清、确认、高风险写入保护和多入口改卡体验。
- 当前发布包仍默认隐藏 Agent 入口；联网搜索界面保持关闭。源码能力保留，但不能据此宣称发布包已开放联网 Agent。

## 验证状态

- 当前 Node 契约测试：1172 项全部通过。
- Rust ARM64/x86_64、ArkTS 和签名 HAP 构建通过；构建产物元数据为 `2.7.9 / 2790`。
- 模拟器覆盖安装和启动已验证；华为真机上的同步、FileOpen 候选列表、权限、媒体拖动和不同屏幕形态仍需人工验收。
