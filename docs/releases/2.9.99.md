# 2.9.99 源码变更说明

更新日期：2026-10-15。当前源码版本为 2.9.99 / versionCode 3080，唯一配置来源是 [AppScope/app.json5](../../AppScope/app.json5)。作者确认的华为应用市场版本为 2.9.98；这两项版本分别维护。

## 本轮功能

- 设备直连：同一 Wi-Fi 或热点下扫码配对，双方授权为个人设备后合并同源卡库的复习历史与学习状态，支持多设备补拉；保留 AnkiWeb，同步范围不包含牌组与媒体传输。入口与验收边界见[同步与设备直连](../development/sync-data.md)。
- 键盘与鼠标：首页、浏览、学习、编辑及模板界面提供对应快捷键说明；牌组支持指针位置的右键菜单，浏览列表与目录树复用已有选择及上下文操作。学习支持撤销与重做、整条笔记操作、提示、上一张卡片信息及学习录音。见[首页](../development/home.md)、[浏览与编辑](../development/browser-stats.md)、[学习与媒体](../development/study-media.md)。
- 编辑与选项：补齐字段格式和焦点快捷键、牌组/类型/模板操作与草稿保留；牌组选项由独立页面持有，提供离开确认、预设管理及修改范围说明。见[首页与牌组选项](../development/home.md)及[浏览与编辑](../development/browser-stats.md)。
- 卡片兼容：统一学习和预览的作者 HTTP 脚本、嵌套请求、授权表单和失败反馈；授权结果由作者服务决定。系统文件打开入口兼容 `application/vnd.anki`。见[学习与媒体](../development/study-media.md)及[APKG 系统打开入口](../development/home.md#apkg-系统打开入口)。
