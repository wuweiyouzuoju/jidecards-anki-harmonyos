# 26.11.22.19 更新说明

鸿蒙版本 26.11.22.19，构建编号 3159。对比应用市场已上架的 26.11.21.18。

1. 新增面向鸿蒙电脑的独立应用「记得闪卡 PC」，与原版可同时安装。
2. 鸿蒙电脑可在实验版「设置 → 高级」开启外部 Agent 接入（MCP）并复制配置。开启后，重新启动记得会恢复接入。
3. 宽屏首页会恢复上次选择；无有效记录时自动选中可见的默认牌组或列表首项。
4. 简化应用识别码界面，识别码以边框突出显示。JIDE 的工具回执和草稿提示不再显示朗读按钮。
5. 移除 JIDE 的单批卡片数量设置，保存、编辑与删除仍需确认。

WorkBuddy 实际连接及最小化后的持续响应尚未完成鸿蒙电脑真机验证。
