# 记得闪卡 3.5.19 源码更新说明

更新日期：2026-10-30。当前源码版本为 3.5.19，构建编号 3100；唯一版本配置为 [AppScope/app.json5](../../AppScope/app.json5)。本页汇总 3.5.4 后当前源码的变化，不表示这些功能已全部上架。

- 统一原生弹窗、菜单、选择器与按压反馈，提供玻璃与扁平材质，调整首页牌组、详情、摘要及学习答题操作区。
- 浏览新增传统多列表格模式，支持独立的卡片与笔记列配置、列替换与排序，并改进多选操作入口。
- 新建和编辑笔记支持正文卡片引用，配套 Anki 电脑端插件；改进字段编辑轮盘、富文本、绘图与草稿预览。
- 提供 12 种语言与地区选项，统一日期、数字等地区格式，并调整长文案和大字体下的布局。
- 完善首页入门、牌组菜单、统计图表与设备直连设置，并同步 JIDE 的功能目录与界面状态认知。
- 保持 Anki Core 调度、AnkiWeb 同步和 APKG 导入导出链路；本轮是原生界面与交互的大范围调整，包含新功能与公共组件重构。
