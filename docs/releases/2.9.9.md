# 2.9.9 源码变更说明

[更新记录](../../CHANGELOG.md) · [项目说明](../../README.md)

整理日期：2026-10-03。本文记录当前工作树相对此前提交的主要变化，不代表应用市场已发布。版本与 SDK 分别以 `AppScope/app.json5` 和 `build-profile.json5` 为准。

## JIDE 应用内助手

- 统一自然语言对话，保留制卡/改卡上下文入口、目标选择、可编辑草稿和确认保存。
- PDF 按页读取、系统 OCR、资料笔记与卡片页码引用；导入资料随会话保存，模型能力决定是否可直接读取页面图片。
- 学习概览、牌组选项和应用设置读取；确认修改部分本机偏好、主题与 FSRS，区分已保存和已生效。
- 独立默认关闭的联网配置，搜索与公开网页读取；本地 QuickJS-NG / wasmi 沙箱只执行纯计算。
- Markdown 表格与离线数学展示、长输出阅读位置、历史恢复及受控错误接续；完善共享模板影响校验与多牌组删除。

当前入口仍需开发者调试解锁。真实模型选择工具、OCR 准确率、设备网络和交互效果须分别验收，详见 [Agent 领域说明](../development/agent.md)。

## 资料编辑与管理

- 笔记录音与音频附件、媒体预览、未保存字段的多模板和填空预览。
- 字段查重、笔记类型字段/模板管理、类型影响说明与文本导出。
- 图片遮罩增加形状和文字编辑，保留未修改的 Core 数据；学习与预览共用渲染。
- CSV / TSV / TXT 导入映射、APKG 更新策略、真实进度与取消，整库替换预检及中断恢复。

入口、格式和限制见[浏览与统计](../development/browser-stats.md)、[数据导入](../development/import-data.md)与[学习媒体](../development/study-media.md)。

## 学习与工程质量

- FSRS 优化、负担模拟和共享预设作用范围；全局日切、提前学习窗口、时间盒和展示偏好。
- 牌组预览会话、音频播放与答案输入修复，主页与主题交互改进。
- 公共表单、按钮、滚动跟随和界面状态声明复用；分离平台适配、模型和写入边界。
- 沙箱测试、双架构构建与警告门禁，隔离 Core 包往返、取消及恢复验证。
- 贡献流程、问题模板、PR 模板和当前文档入口更新。

## 验证与发布边界

验收入口为 `npm run verify`，核心互通另用 `npm run test:interop`。构建与主机回归不证明实体手机、API 21、tablet/2in1、真实 AnkiWeb 或真实模型服务已经通过。各领域的有日期记录描述其当时范围，发布前须在待发布工作树重新执行验证。

未完成的设备/服务验证和发布条件见[开发状态](../DEVELOPMENT_PLAN.md)，互通样本及限制见[核心互通](../development/core-interop.md)。
