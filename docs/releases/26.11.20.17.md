# 26.11.20.17 更新说明

鸿蒙源码版本 26.11.20.17，构建编号 3157。对比上次发布的 26.11.15.15（3155）。应用市场实际上架版本以下载页面为准。

## 卡库备份与恢复

1. 华为云空间改用包含媒体的 Anki 整库备份包，备份所有牌组、卡片、笔记类型、模板、集合配置、复习记录和媒体，减少逐个传输小附件的开销。
2. 修复上传结果误报、下载后牌组或媒体未正确应用的问题。恢复前自动创建本地备份，整库恢复校验通过后才提示成功；继续兼容旧格式备份。
3. 备份列表显示时间和卡片数量，最新备份排在上方，空备份明确显示为 0 张卡片。上传与下载使用加粗箭头图标，并分阶段展示进度、完成数量及可计数阶段的百分比。
4. 首页同步按钮按已配置的方式提供选择，华为云空间上传与下载分别列出，可与 AnkiWeb／自定义服务器和已配对的设备直连入口共同显示；任务进行中再次点击可查看进度。

## 浏览、编辑与学习

5. 优化浏览页首屏加载，先显示前 20 行，继续滚动时再加载更多。大屏分栏按需创建可见编辑字段，延后读取关联计数，减少打开列表和连续切卡时的等待。
6. 修复缩窄再放大窗口、从草稿预览返回及快速切换卡片时的编辑状态问题，保留当前草稿，防止旧读取结果打开错误卡片；离开预览时暂停媒体。
7. 新增双按钮评分，可在答案面只显示“忘记”和“良好”，同时适用于底部和悬浮评分栏；手势及快捷键继续使用各自配置。
8. 改善完整手势设置的操作反馈：设置、移除及恢复默认绑定后显示草稿结果，保存和重新读取有明确提示；恢复默认绑定保留当前启用状态与点击布局，修改“两面”绑定的一面时保留另一面的动作。
9. 学习白板新增截图保存，可将当前可见卡面和笔迹一起保存为 PNG。
10. 编辑轮盘新增“智感握姿”开关，可关闭自动换边并保留手动调整；改善轮盘展开、收起及页面切换时的显示和动画。

## 界面与稳定性

11. 鸿蒙电脑新增窗口置顶。优化短横屏和小窗口的工具栏、摘要统计、牌组详情及操作区布局，改善两侧安全区适配。
12. 优化设置目录读取和入场动画，修复简洁版／实验版切换后目录与说明未及时刷新的问题，减少进入设置时重复读取和旧状态覆盖。
13. 修复外观恢复默认后，输入框等控件的边框未重新显示、圆角或粗细控件未反映默认值的问题；改善首页摘要外观刷新，以及玻璃菜单、弹窗和评分按钮的合成与阴影。
14. 修复隐藏父牌组后子牌组仍出现在首页或搜索结果的问题；改善首次材质引导的保存与重入流程，修复公告检查和导航准备异常可能阻断后续页面的问题。
15. 改善卡片和模板预览的异常处理，避免音频会话初始化或网页控制器异常阻断预览；音频会话失败后可再次尝试播放。

## JIDE 改进（启用后可用）

16. 改善长任务连续执行，不再仅因模型请求或工具调用次数达到上限而暂停。回到同一会话时可尝试接续因后台中断的任务；已有历史会话继续入口保留。
17. DeepSeek Flash 配合 DeepSeek 联网服务新增原生深度搜索和网页读取。配置 DeepSeek 模型密钥后，可使用语音转写、回复朗读，以及按请求对图片或扫描 PDF 使用 DeepSeek OCR。
18. 改善大文件资料导入：本地 PDF 和文本不再受原有 20 MiB 文件拒绝规则限制，PDF 按需逐页读取，原件采用异步复制；其他格式仍受各自解析和大小限制。
19. 模型与联网配置共用“保存配置”，修复同页保存 DeepSeek 模型密钥后，联网设置仍提示缺少密钥的问题；保存失败时保留尚未提交的修改。
20. 鸿蒙电脑 JIDE 通用助手新增本机 MCP 接口，外部 Agent 可通过本次接入配置调用工具。卡库写入、删除和辅助操作继续通过应用内确认。

本包默认隐藏 JIDE，以上相关功能须先启用，部分能力还需配置对应模型服务。外部 MCP 尚未完成 WorkBuddy 实际联调。系统接续、横屏侧边栏、四方向／九宫格手势、图片书画及替换底图在上次版本已存在，不计作本次新增。
