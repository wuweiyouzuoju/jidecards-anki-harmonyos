# 2.9.22 应用市场版说明

更新日期：2026-10-08。本页介绍记得闪卡的 **2.9.22 应用市场版**。

## 下载安装

前往[华为应用市场](https://appgallery.huawei.com/app/detail?id=com.jide.kapian&channelId=SHARE&source=appshare)，或在应用市场搜索“记得闪卡”。支持 HarmonyOS NEXT 手机、平板和电脑。

## 更新内容

- 新增笔记编辑工具转盘，完善可视编辑、格式清理、挖空和 HTML 编辑。
- 优化音频、数学公式编辑及未保存草稿的卡片预览。
- 优化首页、牌组详情、牌组排序、背景设置和菜单操作。
- 完善同步进度、冲突和错误状态显示。
- 优化卡片预加载、翻面、白板与透明批注，修复相关显示和组件加载问题。
- 修复统计范围、学习提醒和桌面服务卡片的问题，统一菜单、弹窗、按钮与图标样式。
- 优化 JIDE 的编辑工具和页面状态同步；JIDE 仍为默认隐藏的开发者调试功能。
