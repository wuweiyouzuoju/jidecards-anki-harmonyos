# 记得闪卡 3.5.0 更新说明

更新日期：2026-10-24。源码版本为3.5.0，构建编号3084；版本事实来源为[AppScope/app.json5](../../AppScope/app.json5)。

## 更新介绍

本次更新带来电脑与鸿蒙互通的卡片引用，让知识点之间的联系更清晰，制卡与查找更顺手。

1. **新增双端卡片引用**：支持在鸿蒙端创建和编辑引用，配合新版电脑插件，在同一套牌组中查看引用与反向关系。
2. **制卡入口更便捷**：在编辑半圆轮盘外圈点击“引用卡片”，即可搜索、选择和预览目标；支持引用选中文字，或在光标处插入。
3. **引用文字独立编辑**：每处引用可使用不同的显示文字，以当前主题色底简洁标识，不额外添加下划线。
4. **搜索输入即更新**：统一牌组、引用、标签等入口的搜索样式，引用候选随输入自动更新；当前引用文字固定在底部，查找与修改更方便。
5. **完善编辑与界面体验**：新建卡片也能建立引用，正文与引用一起保存；优化弹窗分隔线、搜索框间距和选中项留白。

## 使用与兼容

- 电脑端需使用配套新版引用插件，已有旧插件关系可通过迁移入口导入；原始资料包保留。
- 普通笔记类型无需预先添加专用字段或改写模板。引用目标需存在于本地；仅导入一个牌组不自动带入其他牌组的目标。
- 通过原有Anki同步链路交换牌组及引用数据，同一笔记的并发编辑仍遵循Anki的冲突处理。
