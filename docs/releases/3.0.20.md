# 3.0.20 源码与 HAP 开发包

更新日期：2026-10-17。源码版本为 3.0.20 / versionCode 3081，配置来源是 [AppScope/app.json5](../../AppScope/app.json5)。作者于 2026-10-15 最近确认的华为应用市场版本为 2.9.98；此记录不宣布新的市场上架版本。

## 本轮变化

- **设备直连（实验功能）**：扫码配对后，学习记录合并与全部卡库、媒体同步分别取得双端授权。全部同步覆盖牌组、笔记、模板、预设、卡片状态、标签、集合配置与复习历史，媒体按内容差异分块传输。卡库来源或结构不兼容时拒绝普通合并，由接收设备确认使用另一端卡库，并先生成可在本地备份入口恢复的备份。普通合并保留云同步基线；整库替换可能要求下次 AnkiWeb 同步选择方向，并清除当前撤销历史。
- **传输与恢复**：完善取消、离页和迟到发现/认证回调的隔离，保留卡库提交与媒体恢复日志，以及已确认媒体的删除传播。取消或断连不会回滚另一端已提交的数据，尚无断点续传；卡库和媒体需逐对同步，多台在线设备补拉仍只用于学习记录。实现及自动回归入口见[同步与设备直连](../development/sync-data.md)。
- **键盘、鼠标与页面**：统一从“设置 → 学习帮助 → 键盘快捷键”查看各页面操作和当前学习绑定，移除分散的重复帮助入口；完善牌组右键/长按菜单、牌组选项离页生命周期和编辑草稿保护。见[首页](../development/home.md)、[浏览与编辑](../development/browser-stats.md)。
- **深色卡片可读性**：学习与预览共用正文对比度检查，覆盖固定黑字、嵌套浅色块及脚本追加文字，切回浅色恢复作者样式。图片或渐变背景、透明、滤镜等复杂效果仍需逐卡验收。见[学习与媒体](../development/study-media.md)。
- **外观与说明**：移除幻彩限时领赠、解锁庆祝和相关宣传，保留既有主题权益及兑换状态；同步首页入门介绍、JIDE 页面/菜单/设置认知与中英文资源。README、官网指南、HTML、Markdown、JSON、完整文本及更新订阅使用同一轮功能事实。

## 安装包

[GitHub Release v3.0.20](https://github.com/wuweiyouzuoju/jidecards-anki-harmonyos/releases/tag/v3.0.20) 提供 `jidecards-v3.0.20-signed.hap`、`SHA256SUMS.txt` 和构建元数据。安装包作为 Release 附件上传，不将构建产物加入源码 Git 历史。

该包为签名 debug 开发构建，包含 arm64-v8a 与 x86_64 原生库，包名保持 `com.jide.kapian`。安装受签名及设备授权限制，普通用户建议通过[华为应用市场](https://appgallery.huawei.com/app/detail?id=com.jide.kapian&channelId=SHARE&source=appshare)安装。开发设备仅使用 `hdc -t <connect-key> install -r <signed-hap>` 覆盖安装；遇到签名不匹配时不要卸载清数据。

## 验证与边界

本轮发布验证结果和精确安装包 SHA-256 记录在 Release 附件的构建元数据中，复现入口为 `npm run verify`（环境、全部 Node 测试、真实 Core 主机回归、沙箱、RPC/协议、双架构原生库及 clean 签名 HAP）和 `npm run test:cards:browser`（真实浏览器卡片回归）。完整验证规则见[验证入口](../development/verification.md)。

2026-10-17 的完整 `npm run verify` 已通过：3,442 项 Node 检查、真实 Core 主机回归（包含 16 项卡库/媒体同步测试）、沙箱和协议检查、双架构原生库及 clean 签名 HAP，未接受编译警告为 0。编译产物另通过入门页、同步服务器和笔记媒体窗口检查；补齐同步检查工具的当前宿主/凭证依赖后，相关工具与文档专项再次通过，应用构建输入未变化。

编译与自动测试不等于 HarmonyOS 实机验收：真实两机 mDNS、扫码、热点、大库性能和真实 AnkiWeb 账号未完成本轮设备验收，设备直连保留实验标记；本次不执行设备安装。JIDE 入口仍按发布配置默认隐藏，模型服务和写入流程的设备验收边界见[应用内 Agent](../development/agent.md)。
