# 26.11.18.16 更新说明

鸿蒙源码版本 26.11.18.16，构建编号 3156。应用市场版本以实际下载页面为准。以下为相较 26.11.15.15 的用户可见更新。

1. 浏览页先显示首批卡片，继续滚动时再加载更多。横屏分栏切换卡片时，优先载入当前可见的编辑字段，减少等待。
2. 改善电脑端浏览、预览和编辑的衔接。调整窗口宽度时保留当前草稿，从草稿预览返回后可继续编辑和保存。修复快速切换时可能打开旧卡片的问题。
3. 优化设置页的首屏和入场动画，修复简洁版与实验版切换后部分设置入口未及时刷新的问题。
4. 华为云空间上传会分阶段显示附件进度和卡库备份状态，减少重复核对，并修复旧的系统通知导致同步结果误报的问题。
5. JIDE 长任务会保存进度。回到同一会话可尝试自动接续，也可从历史会话手动继续。使用 DeepSeek Flash 并将联网服务设为 DeepSeek 后，支持深度搜索和网页读取。
6. 配置 DeepSeek 模型密钥后，JIDE 支持语音转文字和回复朗读，也可按请求使用 DeepSeek OCR 识别图片或扫描 PDF。修复同一页面保存模型密钥后，联网设置仍提示缺少密钥的问题。
7. 改善玻璃菜单和弹窗的背景合成，减少局部发灰和异常染色，修正编辑轮盘展开动画。
