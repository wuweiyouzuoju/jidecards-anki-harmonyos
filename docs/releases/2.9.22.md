# 2.9.22 源码变更说明

[更新记录](../../CHANGELOG.md) · [项目说明](../../README.md)

更新日期：2026-10-07。本说明记录当时 2.9.22 / 3003 的源码变更，不代表应用市场已上架。当前源码版本以 [AppScope/app.json5](../../AppScope/app.json5) 为准；后续版本元数据调整见 [2.9.88 变更说明](2.9.88.md)。

## 更新说明

1. 新增笔记编辑工具转盘，完善富文本、格式清理、挖空和 HTML 编辑，常用制卡工具更方便使用。
2. 优化音频与数学公式编辑，完善未保存草稿的卡片预览。
3. 优化首页与牌组详情布局，调整牌组排序、背景设置及菜单操作。
4. 完善同步状态显示，便于查看账号、同步进度、冲突及错误信息。
5. 优化学习卡片预加载与翻面流程，修复卡片显示和牌组预览中的相关问题。
6. 完善学习白板与透明批注，支持保存批注外观，修复手写组件加载和后台切换时的异常。
7. 修复统计范围切换、学习提醒和桌面服务卡片的相关问题。
8. 统一菜单、弹窗、按钮及图标样式，优化设置页面与幻彩主题解锁反馈。
9. 优化 JIDE 的编辑工具与页面状态同步，完善上下文处理、取消操作和历史记录兼容。

## 实现记录

- 首页：调整宽窄布局、顶部动作区、牌组详情和列表排序；常驻同步按钮显示账号、传输、冲突及错误状态；牌组背景支持图片处理和统一菜单手势。
- 编辑器：新增工具转盘与对应图标，完善富文本、光标选区、格式清理、挖空和 HTML 工具；更新音频、数学公式及未保存草稿预览。
- 学习与预览：预取卡片渲染数据、复用 Web 缓冲，修复卡片视口和翻面流程；完善牌组预览的空结果与会话恢复。
- 白板与批注：增加透明卡面批注和外观保存；完善本地白板、Pen Kit 动态挂载、上下文、超时及隐藏/后台回调隔离，保持不可用时的回退。
- 统计与提醒：修复统计范围和异步会话更新，整理牌组元数据、提醒与桌面卡片存储的初始化和释放入口。
- 公共界面：统一菜单、弹窗、按钮、标签和图标；调整设置、笔记类型模板预览和幻彩主题解锁反馈。
- JIDE：同步首页、设置和编辑器的真实入口、图标与状态；完善上下文预算、取消状态和推理历史兼容。
