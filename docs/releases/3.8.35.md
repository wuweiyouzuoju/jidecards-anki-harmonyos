# 记得闪卡 3.8.35 源码更新说明

日期：2026-11-01。当前源码版本 3.8.35，构建编号 3136，以 [AppScope/app.json5](../../AppScope/app.json5) 为准。作者确认目前应用市场已上架版本为 3.8.1；以下汇总其后源码改进，不将其写为市场已发布功能。

- 完善字段展开窗口：保留当前字段草稿和编辑模式，补齐输入边界，移除展开窗口中重复的模式按钮。
- 统一页面玻璃背景：设置、学习、编辑、浏览、牌组选项和预览外层随材质切换，玻璃时透出根背景，扁平时保留原底色。
- 提高字段模式按钮文字对比度，依据实际主题实底选择黑色或白色文字。
- 首页入门按 Anki 经验分流，新用户增加闪卡、准备第一副牌组与日常复习教学；完成选择并保存后才进入导入、新建或同步。
- 完善浏览多选完整计数、牌组快捷操作及自定义学习数值记忆。
- 统一弹层融合、定位与关闭行为，修复主题色开关、深色轮廓和公共材质一致性。

实现和设备记录见[首页](../development/home.md)、[浏览与统计](../development/browser-stats.md)、[材质规范](../development/material-standard.md)及[界面](../development/appearance.md)。调度、集合、同步沿用原领域和 Anki Core；旧版本功能不重新列为新增。
