# 26.11.15.15 更新说明

源码版本 26.11.15.15，构建编号 3155。应用市场版本以实际下载页面为准。

1. 横屏大窗口新增侧边栏主页，可在「设置 → 常规 → 横屏大屏主页」切换，搜索、浏览、同步和新建集中在侧边操作。
2. 新增华为云空间手动同步入口，可同步卡库并查看其他设备的备份。需使用同一华为账号，并在系统云空间中开启本应用同步。
3. 外观自定义可分别调整文字、模块、按钮和弹窗的颜色与边框。调整后自动保存，色环与色块之间留出间距，减少误触。
4. 添加卡片时可直接打开白板书画，工具区布局更紧凑，图片操作与输入框的间距也做了调整。
5. 优化大屏设置目录和统计页牌组筛选的布局，改善新增卡片时固定字段图钉的显示。
6. 调整菜单、弹窗和玻璃材质的显示，修复部分弹窗被遮罩挡住、内容未正常出现的问题。
7. 修复打开牌组卡片预览，以及添加或编辑卡片时富文本输入可能引起的闪退。
