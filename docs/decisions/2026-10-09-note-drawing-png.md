# 制卡书画源随 PNG 保存

2026-10-09，当前决策。

制卡图片与空白书画使用同一编辑器，完成后沿原图片草稿和 Core 媒体导入入口保存。原“新增图片或视频”保留，新白板按钮放在其下；图片笔形入口复用公共图标按钮。手写默认复用华为套件，平台不可用时复用本地笔迹模型；已保存的华为笔迹不自动转成平面图或另一引擎。

普通 PNG 是卡片显示与 Anki 媒体互通的文件。可编辑源存入私有辅助块 `jiDe`：包含规范化底图、本地笔迹或 SDK 不透明保存文件，以及文字对象。源随同一个媒体文件同步/导出，无需新增集合协议、共享数据库或未被字段引用的旁文件；现有 PNG 导入保留原字节。外部重编码可能移除辅助块，届时只把图片当普通底图编辑。

文档格式、几何与源大小验证归 [NoteDrawing.ts](../../entry/src/main/ets/model/NoteDrawing.ts)。平台解码、源文件恢复与独占缓存归 [NoteDrawingStore.ets](../../entry/src/main/ets/backend/NoteDrawingStore.ets)。SDK 保存/加载/缩略图通过既有动态宿主，源数据只在本次独占工作目录展开；不直接静态加载可选系统 HSP。编辑器完成生成新文件，媒体完成才交字段，保存笔记才持久化；取消不覆盖原图或删除 collection.media。

文档版本目前为1，源最多32MiB，合成 PNG 最多64MiB。后续格式变更须保留版本识别和失败边界。SDK 文件保持不透明，跨 SDK/设备可恢复性由平台决定；加载失败可退出保留原图，不声称已转换成功。JIDE 仅观察控件与状态，不接入图片、笔迹、文字内容或原始文件。

验证入口为 [note-drawing.test.mjs](../../tools/tests/note-drawing.test.mjs)，已纳入 media 筛选，另需增量 HAP。测试替身只验证调用和文件保真；华为实际书写、保存/载入、缩略图透明度与裁切、图库权限和宽窄屏/键盘布局须独立设备验收。当前功能与边界见[制卡图片书画](../development/browser-stats.md#制卡图片书画2026-10-09)。
