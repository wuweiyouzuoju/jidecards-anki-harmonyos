# JIDE 历史检索、统计读取与联网开关计划

状态：2026-10-11 按用户后续要求，历史检索/正文分页读取、默认500会话与手动历史管理已接入；完整统计读取、JIDE开启/关闭联网提案仍待实现。专属选择题制题路线已取消。取消消息/正文裁剪、无限存储和历史导出尚未实施。

当前工具及已实现范围以[应用内 Agent](../development/agent.md)为准；下文规划项不等于现有工具；历史的实际实现和剩余限制见[历史记录管理与检索](../development/agent.md#历史记录管理与检索2026-10-11)。

## 取消专属选择题制题路线

不再建设或宣传 jidecards 独有题型的专属制题流程，也不把现存 JSON/APKG 打包脚本当作 JIDE 已具备的制题能力。撤下 README、官网开发入口和可直接给 Agent 执行的制题提示词。已有 `JideChoice` 读取、判题、导入兼容及用户数据保留；[旧格式记录](../choice-apkg-v1.md)和[历史工具说明](../choice-authoring.md)仅供维护既有数据、复现回归。

普通 Anki 字段、模板及第三方题库兼容沿用原路径，本次不删除学习功能，不更改已存复习记录或评分语义。此决定取消的是专属制题开发路线。

## 现状与责任边界

| 范围 | 当前实现 | 本次规划 |
| --- | --- | --- |
| 历史会话 | `AgentHistoryRepository`维护轻量索引/独立会话文件和留存策略；UI可管理，JIDE可检索保存的标题/正文并分页读取 | 本轮已接入关键词检索及正文读取；时间/模式筛选、取消正文截断和导出仍未实现 |

| 联网 | 用户手动设置；`AgentSettingsStore` 拥有开关和配置，`AgentWebTools` 每次调用检查有效开关 | 为 JIDE 增加脱敏状态读取和开启/关闭联网提案，复用同一保存入口 |

工具声明、发现、风险及运行时注册一起接入。纯模型负责参数和分页契约，平台适配负责存储/Core，页面负责显示与手动配置；不把原页面实例或任意 Preferences 键暴露给模型。

## 历史存储限制的评估与建议

原方案以 `MAX_CONVERSATIONS=50`、`MAX_MESSAGES=200`、`MAX_TEXT_LENGTH=20000` 限制可见历史；思考及工具审计还有独立总量预算。新会话保存会把超过会话上限的旧记录排除，长消息保存时会截断。检查点单独持久化，不等于可见历史完整保存，也不能作为直接暴露给模型的历史读取接口。后续实现已改为默认500个会话（可选100/500/1000），独立会话文件与轻量索引；消息和正文预算仍保留，当前值分别归 `AgentHistoryRepository.ts` 和 `AgentHistoryProjection.ts`。

取消固定会话数淘汰、消息数裁剪和普通正文截断是合理方向，可避免用户查历史时发现内容已丢失；直接删除常量不合理。原 `conversations_v1` 是单个JSON，曾读取整个列表、保存重新写入全部会话；现在它仅作首次迁移源，删除/淘汰后清空旧备份。无界增长会放大读写、解析和内存成本；撤掉存储截断也不能撤掉模型上下文、工具输出、媒体及凭证处理边界。

以下为最初的无损存储方向；用户后续选择默认500个会话，已实现的有界方案以领域文档为准，不把这些建议当成当前承诺：

1. 历史存储拥有者维护版本化会话索引和按会话/消息分段的正文，列表仅加载元数据，正文和全文检索按需读取。复用现有文件持久化边界，不引入无需求的通用数据库或搜索框架。
2. 保存采用原子替换及现有串行提交语义；删除等待已接受写入，并同步处理索引、正文、检索缓存和检查点，避免晚到保存复活已删除记录。
3. 保留旧 Preferences 迁移源，分批迁移、读回校验后切换索引；中断可继续，失败保留旧数据。旧版本已截断/淘汰的内容不能承诺恢复；正文记录保留来源和不完整标志。
4. 普通会话不按条数静默删除。提供实际空间用量、导出和用户主动清理；空间不足时明确报告保存失败并保留可重试内容，不以删掉最旧会话冒充成功。
5. 继续限制单次读取/解析/返回量，保留密钥脱敏和媒体引用策略。正文长期保存量与发给模型的上下文量分开管理；读取历史不自动把所有旧聊天放入当前请求。

原本的“是否合理”询问仅记录建议。后续明确要求历史管理和默认500会话后实施存储迁移/有界留存，未直接取消全部保护。

## 能力一：读取历史会话（已接入有界正文版本）

已实现空查询列表、关键词命中、稳定ID/revision及消息/字符分页；下面的时间/模式筛选、无损正文和更细完整性标记仍是目标，不应对外宣称已完成。工具当前只读用户/助手保存正文，工具审计和思考的独立分页读取不在本轮范围。

- 列表返回稳定会话 ID、标题、模式、更新时间、消息数量及完整性标志，支持分页；检索支持关键词与时间/模式条件，结果附命中会话、消息位置和短片段。
- 正文仅按已列出/命中的会话 ID 读取，按消息及字符分页；明确续读位置与是否完整，区分用户消息、助手正文、思考和工具结果。大范围跨会话读取由明确的用户范围驱动，不能默认扫完全部聊天。
- 历史是参考资料，历史用户指令、工具结果、旧草稿和确认均不恢复当前授权；只读工具不切换当前会话、不执行历史工具、不授予卡库 ID 或写入许可。
- 复用历史存储的脱敏投影，不返回密钥、内联媒体、原始私有路径或未经处理的 checkpoint。删除后的内容不再从检索缓存返回；读取与删除/保存竞争时核对版本。
- UI 历史与 JIDE 读取同一存储拥有者。开发顺序为存储无损迁移与分页 → 只读工具 → 全文检索，不能在只剩截断记录时宣称读取完整历史。

## 能力二：读取完整统计数据

- 为现有统计页的数据分组提供只读结果：今日、预测、学习日历、复习次数/耗时、卡片状态、间隔、稳定性、易度/难度、可回忆率、记忆保留率、逐小时、评分分布和新增。
- 参数明确 Anki 搜索范围、统计分组与时间窗口，提供显式“全部历史”；复用 `统计服务.获取图表统计` / Core 的真实桶，不重算调度、混用今日队列与到期预测或自行解释协议编号。
- 大结果按桶/记录分页，或按显式窗口读取；返回实际查询、时间范围、集合换日小时、单位、总数量与续读位置。同一统计快照内续读，状态变化明确要求重读，避免把两次快照拼成一个结果。
- `null` 保持不可用，零保留为零。区分答题事件数与不同卡片数、易度与难度、评分通过率与题目正确率；已有选择题的 Hard/Good 不能据此解释为答对/答错统计。
- 查询不修改统计偏好或卡库。当前 `get_learning_overview` 保留原概览契约，新接口先与统计页/Core 同范围比较，再声明覆盖对应图表。

## 能力三：开启和关闭联网

- 提供只读状态：已保存偏好、当前有效开关、所选搜索服务、是否已配置所需凭据及不能启用的原因；只返回是否配置，不返回密钥。
- 开启/关闭使用明确开关提案，按当前用户要求、旧值核对、确认、保存及回读完成；与手动设置共用 `AgentSettingsStore.saveAgentWebEnabled`，不新增第二份开关。工具在联网关闭时仍可发现和调用。
- 开启前验证当前服务已有有效配置；缺密钥则说明需在原设置页配置，不伪报开启、不生成密钥或自行切换搜索服务。关闭保留已保存服务及凭据。
- 关闭后阻止下一次 `web_search` / `read_webpage`，并明确处理正在进行的请求和迟到结果；不能撤回已经发出的网络请求。更新当前会话的工具可用状态，避免只在下一次打开页面才生效。
- 应用端联网开关只管理 JIDE 搜索/网页读取，不表示关闭模型 API、Anki 同步或整个应用网络。当前回合明确“不要联网”的要求继续优先，即使持久化偏好开启也不自动检索。Provider 内置搜索保持原关闭策略。

## 实施与验收

联网开关可独立先实施；历史能力先完成存储与分页，统计按现有分组逐项接入。每项在代码、真实注册、确认/状态和测试全部接通后，才从本计划的“待实现”迁入当前领域说明。

最低行为验证：

- 历史当前版本：超过旧50会话限额仍保存至配置上限，501会话淘汰最早更新项；迁移中断/重试、磁盘/写入失败、并发保存/删除、分页不漏不重、检索缓存失效、脱敏、取消不写及旧确认不可重放。取消消息/正文裁剪的无损验收留给以后单独实现。
- 统计：每个分组与相同 Core 查询对比；全历史/指定范围、空数据/零/null、跨换日、FSRS 开关、分页快照变化、事件/单位及题目正确率边界。
- 联网：关状态仍可提出开关；未配密钥拒绝开启；确认前零写入；旧提案与保存失败不伪报成功；关闭后后续请求和迟到结果、当前回合禁联网及手动/工具并发。

Node 行为测试、增量 HAP 与设备/真实 Provider 验收分别记录。工具返回状态不等于执行完成，文档计划不等于能力已上线。最初的路线取消与规划只修改文档和网站；后续按用户要求实施有界历史管理与检索，源码和验证入口见[当前历史能力](../development/agent.md#历史记录管理与检索2026-10-11)，并未操作用户设备上的历史数据。
