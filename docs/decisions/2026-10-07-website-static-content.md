# 官网静态内容与机器读取

日期：2026-10-07。状态：已实施。

## 决策与原因

官网以 AI 读取与爬虫抓取为首要目标。正文、导航、功能状态和更新说明在构建时生成完整 HTML，同时输出逐页 Markdown、完整文本和 JSON 索引。用户与爬虫访问同一份正文，阅读和导航不依赖客户端 JavaScript。

沿用已有 Node 静态生成器，将事实加载、公共布局、页面模板和文本导出分别放入 `tools/site/`。参考 [Astro 的内容站点与默认零客户端 JavaScript 原则](https://docs.astro.build/en/concepts/why-astro/)以及 [Vite 官网的产品、文档和开源入口](https://vite.dev/)组织信息。当前页面只需要静态内容和原生 HTML 导航，没有引入框架运行时的需求。

为响应“先进入，再加载图片”，增加一个仅负责图片加载的可选模块：Logo 小图内嵌，宣传图预留真实尺寸；正文首次绘制后，接近视口才下载原图。阅读、导航与机器格式仍不依赖脚本；禁用脚本时使用 noscript 原生图片。此增强不引入客户端内容渲染或改变爬虫正文。

## 事实与素材边界

正式版本由作者确认，记录在 `hosting/data/works.json` 的 `releaseVersion` 与 `releaseVersionSource`。源码版本由 `AppScope/app.json5` 读取，两个字段分别表达事实。作者本次指定正式版为 2.9.22。

宣传图采用作者提供的新版 PNG，版本、说明、尺寸和 SHA-256 保存在同一产品数据中。构建校验素材字节和版本，不能继续引用过时截图。旧截图留在 Git 历史和本地文件中，通过资产排除规则停止发布。应用 Logo 复用 AppScope 图标原始字节。

## 影响范围与验证

影响网站生成器、`hosting/` 页面与抓取入口、网站部署工作流。应用公告和云端牌组协议独立维护，域名重定向仍由现有 Worker 负责。

运行网站、Worker 和文档契约测试；桌面与手机宽度检查实际布局、图片和导航；上线后读回 HTML、Markdown、JSON、XML 和素材，比较本地字节，检查旧图片已停止服务以及域名 301 保留路径和查询参数。这些检查验证网站发布，不替代应用、原生引擎或设备验收。

操作入口见 [官网内容与部署](../site-deployment.md)。
