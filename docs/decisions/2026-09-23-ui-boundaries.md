# UI 边界与过期月历清理决策

## 背景

本次审查发现首页曾保留“月历”数据模型和组件，但首页月历页面已在 2026-08-15 的产品决策中移除。当前仍有效的是统计页的年历热力图（`components/stats/日历卡.ets`）；首页不再渲染 `components/月历卡.ets`。

## 本次落地

- 统计页年历直接消费统计数据；主页快照不再携带只供旧月历使用的按日期统计字段，避免过期数据契约继续扩散。
- 浏览页表格改用 `IDataSource` + `LazyForEach`，行 key 使用稳定的业务 ID，避免大列表每次状态变化时全量重建。
- 浏览页分页加载状态由宿主请求的 `Promise` 生命周期关闭，移除固定 1 秒定时器，防止请求未完成时重复触发或请求很快结束后无谓锁定。
- 添加笔记页引入 `NoteSaveLifecycle`：已经开始的写入继续完成，但页面离开后禁止旧页面导航和错误状态回写。
- 修复构建脚本的 PowerShell 单元素数组展开问题，增量构建稳定传递 `assembleHap`。
- 删除首页未使用的月历 UI 状态和导入，避免过期功能继续扩大页面组件职责。

## 结论

“月历”作为首页 UI 已过期；统计页年历仍是当前功能。主页快照消费者已清理后，旧的首页月历组件和模型已删除。
