# 2026-10-01：应用设置能力与 Agent-first

## 决策

每项新增助手能力同时提供明确业务入口、工具契约、真实行为测试和当前领域文档，持续降低编程 Agent 的定位及修改成本。应用内助手与设置页面共用领域业务能力，各自保留输入与展示责任。

接入设置目录、20 项外观/学习/同步/备份/统计偏好读取、完整公开牌组预设读取、主题色目录、可撤销深浅色切换，以及确认后主题色和全库 FSRS 修改。`AgentSettingsTools.ts` 汇总设置定义和工具契约，既有 AgentToolCatalog 汇总声明；AgentAppSettingsTools 注册真实实现。偏好读取使用固定语义 ID 白名单，公开配置单独列出并标记截断；暂不提供任意偏好键、通用配置写入或牌组选项修改。

## 授权与状态

明确的当前用户切换指令可以直接修改本机主题；设置工具使用独立 `setting_write` 分类和一次性单轮许可，不能借 read 注册入口写入。卡库草稿、辅助提案和高风险确认维持原边界。许可不来自笔记/附件/记忆，不进入历史，恢复或继续不重放。

AppThemeService 拥有唯一 ThemeModeSession 队列，设置页与助手共用严格保存、回读与应用。结果区分持久化和生效，不能把失败当默认值或成功。各页面订阅公共主题状态。撤销凭据仅在本进程有效，后续修改失效，撤销前重查保存值，防止覆盖用户的后续手动设置。

主题色与 FSRS 以既有辅助动作确认，沿用原始载荷账本与独立执行器，不另建确认协议。主题色使用共享 ThemeColorSession；FSRS 初始化、设置页与助手使用控制器串行队列，确认时校验原值，同状态不重排。

统一输入、效果、范围、授权、结果/错误及入口/验证的语义；保留各领域的载荷和执行器，避免万能操作工具与全项目重写。新能力按真实重复逐步复用。

## 验证入口与限制

- `npm test -- agent`：真实 Registry 与设置工具、输入许可、作用范围和失败反馈。
- `npm test -- ui`：真实主题队列/存储、撤销冲突与页面订阅接线。
- `npm run verify`：全仓 Node、原生与签名 HAP；实际结果由本次交付记录，不用文档宣称已通过。
- 真机需另验设置与助手双向切换、跟随系统、跨页刷新、撤销、重启持久化，以及失败文案；确定性工具测试不代表真实模型决策质量或设备交互已验收。
