# JIDE 操作接入

此前存在手动入口但 JIDE 无法执行的操作，统一接入实际工具、确认草稿和领域拥有者。完整能力表与限制以 [应用内 Agent 开发说明](../development/agent.md#卡库与应用操作接入2026-10-11) 为唯一事实来源。

`model/agent/AgentOperations.ts` 是新增操作的声明、严格参数校验和确认快照入口。领域适配器只提供真实读取、准备快照与执行；写入经 `AgentDraftExecutor` 原确认协议，高风险保留双重确认。应用登记完整草稿指纹，确认后重读真实状态，接受内容被冻结并单次消费；历史恢复、执行失败和重试不恢复命令许可。结果通过 `get_operation_result` 按字符分页读取，保留真实完成、取消、部分失败或未知状态。

这样处理是为了复用 Core 的调度和修改语义，并让手动入口与 JIDE 共享持久化、并发和失败处理。应用界面观察不增加任意点击、文件路径或凭证权限；登录、同步冲突、系统选择器、CSV 映射、集合覆盖和图片裁剪仍由原流程拥有。宿主只在原流程到达实际终态时回传结果，等待用户操作或打开面板不算完成。

媒体维护使用已确认检查产生的有效快照；提醒区分已落盘与通知发布失败；学习评分绑定原卡片、页面代次与实际正反面，内容待刷新或会话不可用时拒绝。牌组外观、隐藏状态、提醒、统计偏好等本机写入使用共享拥有者排队并核对旧值，避免手动修改和 JIDE 相互覆盖。

2026-10-11 验证：`npm run verify` 通过，包括3320项仓库测试、原生 Core、沙箱、协议索引/互操作和干净 HAP 构建。收尾的学习状态、音频失败、筛选配置及本机并发修正另通过100项专项回归和增量 HAP 构建；新增编译警告为0。核心行为测试入口是 `ai-agent-operations.test.mjs` 与 `ai-agent-operation-workflows.test.mjs`，并覆盖原学习、导入、设置及同步领域回归。

此次未安装应用或变更设备数据。ArkUI 实际交互、系统选择器、通知权限、真实账户登录和联网同步尚未实测；主机替身及 HAP 编译不代替这些设备验收。
