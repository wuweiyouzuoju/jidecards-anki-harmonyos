# 重建说明

2026-10-15，用户明确要求旧「可移植积木」整套退出并重新实现。旧目录及上一轮暂放其中的规范共 24 个文件已移至`项目资料/记得系列基础/归档/2026-10-15-旧可移植积木`，逐文件 SHA256 核验结果见`项目资料/记得系列基础/归档/旧资产归档清单.json`。工作区不再保留可继续接入的旧目录。

2026-10-29核对：上述归档未随当前Mac工作区迁入，路径仅作历史记录；不以本机不存在的归档作当前验证依据。新版显式选择的视觉材质见[界面与交互](界面与交互.md)，几何、材质、业务状态仍分开维护。

## 为什么重建

旧浮层把模糊、阴影、动画和许多几何参数捆在一个组件；旧令牌对应早期舒尔特样式；旧按压另设触摸/缩放状态；旧系统主题读取会被应用强制主题污染，并把读取失败当浅色。这些与当前产品的责任入口、外观和失败契约不一致，不能通过更名或重新写一份 README 继续当成新基线。

## 替换结果

| 旧实现 | 新入口 | 本次改变 |
| --- | --- | --- |
| GlassOverlay 与旧主题令牌 | SurfaceLayout、DialogSurface、UiTokens、Theme | 将纯几何与平台展示分开，只保留需要的共用语义；无默认模糊/外阴影或可变全局状态 |
| AnimatedPressable | Motion、FoundationPressFeedback、ActionButton | 使用原生按压属性与点击守卫，取消独立触摸状态和延迟；正常/禁用均恢复缩放 |
| EmptyState | StateView | 文案与真实动作由宿主提供，加载期间不提供动作；无 Text 伪按钮或旧色板 |
| ThemeColorModeListener | resolveDarkMode、readSystemDarkMode | 使用设备资源入口；不写 AppStorage、不把读取失败伪装成浅色，生命周期仍归宿主 |
| DateKit | CalendarDay | 收紧到严格日历日与跨日运算，覆盖夏令时、闰年和低年份；展示格式交回产品本地化 |
| HapticFeedback/SystemHaptics | core/Haptics、harmony/SystemHaptics | 规则/后端分离，显式偏好，最终设备失败上抛，无隐式全局开关 |

新 API 不与旧名称兼容。重建前对闪卡、魔方、舒尔特、空间训练、计算器和养个棋源码/配置扫描，未发现指向旧公共目录的直接依赖；此结论不代表所有历史资料或未知工程都无需迁移。

## 当前范围与后续

旧积木的重建与整个 jidecards 复用体系的抽取是两个范围。先前只完成首批 12 个模块，范围收窄；现已补充[完整盘点入口](复用全景.md)及[跨产品接入规范](跨产品接入规范.md)，逐项区分已跨产品使用、仅内部公共复用、结构借鉴和本基础实际覆盖。

当前交付包含可执行纯规则、HarmonyOS 组件/适配、行为测试、独立编译夹具、真实公共 HAR，以及规范和来源记录。魔方与空间训练已将图标绘制、图标按钮、按压、箭头及两组成对 SVG 改接公共包，入口与差异见[公共 HAR 接入](公共HAR接入.md)。其他成熟能力尚未整体迁入，产品已有业务、用户数据和技术决策继续由原项目维护。

等级机制仍由已创建的新对话逐项向用户提问决定；不把空间训练现有的五局一级提升为全系列标准。
