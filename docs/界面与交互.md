# 界面与交互

依据：闪卡公共组件索引、当前界面约定、尺寸源码，以及魔方、舒尔特、空间训练的现有映射。本次实际实现入口见[复用目录](复用目录.md)；下列跨产品参考不等于所有列出的控件均已重新实现。

## 可沿用的公共几何

| 语义 | 参考值 | 注意 |
| --- | --- | --- |
| 页面水平留白 | 12 vp | 安全区由窗口/页面宿主提供 |
| 卡片或弹窗内边距 | 16 vp | 外壳贡献一次，正文和标题不重复叠加 |
| 常规分组间距 / 表单行间距 | 12 / 8 vp | 闪卡窄密度另有 8 vp 页面分组档，不能机械推广到所有页面 |
| 工具栏图标按钮 | 44×44 vp 热区，18 vp 图标 | 矩形表面通常 18 vp 圆角；圆形按直径处理 |
| 普通文字操作 | 最小 44 vp，参考 22 vp 胶囊圆角、15 字号 | 长文案按组件契约换行或适配；完整名称用于读屏 |
| 训练/学习主动作 | 52 vp、26 vp 圆角、17 字号 | 闪卡与魔方/舒尔特已有采用；不要求所有确认按钮同样大小 |
| 卡片 / 输入与选择器圆角 | 18 / 16 vp | 不覆盖已有内容专属几何 |
| 普通弹窗 | 宽 88%，常规最大 480 vp | 紧凑 420、宽内容 560 vp 是闪卡/魔方现有档位，按内容选用 |
| 弹窗正文 | 按可用安全区、键盘、实际标题和操作栏预算限高 | 内容少时收缩；普通表单避免嵌套滚动 |
| 折叠箭头 | 24 vp 槽位，收起向右、展开向下 | 使用几何组件，绑定真实展开状态 |

字号按语义对齐，不能将不同产品所有文字统一到一个数。闪卡常用 14 正文、15 控件、18 卡片/弹窗标题、20 分区标题；舒尔特正文层级和展示标题有自己的映射。采用时从目标组件和资源读取，检查长中文、英文、大字体与窄屏。

## 表面、颜色与图标

- 既有页面继续保留扁平表面；新版系列视觉由产品显式采用 `SharedSurface` 的玻璃或扁平材质，配合 `SharedPageBackground`、`SharedActionButton`。投影与模糊只由公共表面拥有，不复制到页面；减少透明度时回到不透明表面。参数与边界见[视觉基础接入](视觉基础接入.md)。
- 页面、卡片、主要/次要文字、边框、动作、危险和禁用使用语义颜色；明暗资源成对。不能复制整份颜色表并把闪卡专用键当作通用业务。
- 同义动作复用已有 SVG 与公共绘制入口；完整点击名称供无障碍使用。直接导航常用透明内填与动作色描边，菜单使用对应的填色语义，两者分别处理。
- 主学习/训练动作可采用卡片底与动作色文字；普通业务确认保留其实色语义，危险动作保留错误色与明确后果文字。选中态只表示真实状态，不用于装饰。
- 已有产品的模糊/背景策略存在差异：魔方映射保留薄模糊蒙层，舒尔特当前应用卡片与弹层无模糊，闪卡主题还含玻璃渐变。新增产品采用前记录选择，不能宣称全系列已经完全同样呈现。

## 控件与关闭策略

优先查公共索引，依次选择直接复用、组合/适配、修改公共入口；只有已有语义不能表达时才新建。基础 UI 接受数据、可用状态和回调，不直接操作业务存储或引入闪卡服务。

- 加载、空内容、读取失败分别呈现；没有重试回调时不显示虚假的重试按钮。
- 设置行共用图标、标题、可选说明/帮助与尾部槽位；长说明自然换行。选择器、开关和动作行的不同语义不混为一种控件。
- 标题确认/保存/完成可以复用图标按钮，同时保留完整读屏名称；危险、下载、迁移等需要表达后果的动作保留可见文字。
- 系统返回、遮罩、关闭按钮进入同一业务关闭策略；最上层优先。键盘、子弹窗、草稿与忙碌守卫由各自所有者处理。
- 确认才提交，取消或返回不偷偷写入；提交已接受后关闭界面不等于回滚。保存失败保留可重试内容并说明当前状态。
- 弹窗外壳拥有尺寸、安全区、正文预算与一次转场；宿主不再重复加 padding 或动画。平台系统窗口继续保留其交互边界。

## 按压与动效

公共链：MotionStyle → AppMotion → PressFeedback。空间训练已有直接复用，其他产品采用各自适配入口。

| 选择 | 当前来源参数 | 已有差异 |
| --- | --- | --- |
| 克制 | 菜单 0.98、150 ms，按压缩放 1 | 闪卡默认；空间训练当前采用默认克制 |
| 灵动 | 菜单 0.94、220 ms，按压缩放 0.975 | 舒尔特明确采用灵动相关参数 |
| 普通按压 | opacity 为原值×0.72；禁用最多 0.4；恢复缩放 1 | 具体表面色层由目标公共组件提供 |

只复用目标真正需要的参数。动效不延迟业务点击、不改变判题/评分/计时，不通过增加触摸状态抢占手势。显示答案、换题或常驻宽屏侧栏选择不自动等同页面导航。震动与动态背景由独立偏好拥有。

旧按压、浮层和令牌已从活动目录退出，不再作为接入候选。新基础采用[Motion](../src/core/Motion.ts)与[原生按压适配](../src/harmony/PressFeedback.ets)，动效档位由宿主显式传入；来源产品可以继续使用其既有适配，尚未被批量改接。旧/新替换关系见[重建说明](重建说明.md)。

## 验收

检查最终外观与操作：深浅色、窄/宽屏、大字体、长标签、键盘、禁用、失败重试、取消/返回、连续开合及后台恢复。安全区与间距按控件最终外缘测量，不能把某一段 padding 当作总距离。闪卡 a=b=c=d 和状态栏文字的光学估计是其页面专项约定，不能作为所有设备的系统保证。

主机回归证明模型/编排，HAP 证明编译；像素、读屏、触摸分发、原生选择器及 GPU 呈现需相应设备证据。具体命令使用目标项目[验证入口](复用目录.md)。

## 跨平台按钮宽度与选择弹窗稳定性（2026-10-26补充）

按钮按语义确定宽度，不能全都填满父级或统一固定宽度。同级页签/互斥选项组统一等宽等高，按最长文案和可用宽度整体换行；行内筛选按内容占宽，图标使用固定热区，表单选择框使用一致槽位。窄屏英文不能出现拆词和同组高低不齐。界面主动作与辅助动作的层级仍保持差异。

选择弹窗的锚点、选项行和勾选槽位在悬停/选中时保持尺寸稳定；父级计时刷新不重建展示状态。分别验证点击、取消、反复展开、父状态刷新和实际指针悬停，不能以截图代替悬停验收。

iOS 的实际公共实现、尺寸规则及本轮证据边界见 记得系列 iOS 控件布局规范。上述行为约定跨平台适用，iOS的pt与原生菜单不机械替换鸿蒙的vp和窗口实现；本轮未修改鸿蒙组件。

## 选择菜单与内容弹窗的职责（iOS补充）

普通枚举沿用 iOS 原生系统选项菜单，尺寸/材质/滚动由平台安排；带说明、表单、多步操作的内容才套用系列内容面板预算，危险确认另保留明确后果和取消。不能把系统选择菜单改成300/340pt的大内容气泡，不能为修复悬停闪烁顺带改变原有外观。原生锚点要持久，父级计时/渲染刷新不重复替换菜单；只有候选、选中或可用性真实变化时才更新。各平台保留其原生宿主，不把UIKit实现机械搬到鸿蒙。细则与实测边界见 iOS系列规范。

## 新版视觉档（2026-10-29）

新增16vp页面留白、22vp卡片圆角、16vp卡片内边距与52vp最小学习动作，统一静态氛围背景、柔和表面和按钮；使用 `VisualTokens`，不覆盖旧 `UiTokens`。这些值参考当前iOS JideCards的视觉关系，鸿蒙保留自己的vp、原生Button、材质和按压语义。长文案允许自然换行，不把52vp当作强制高度。

`SharedSurface`不拥有padding、转场或关闭；现有弹窗可采用同一表面，但原生窗口、安全区、滚动预算和草稿守卫继续由宿主维护。0.2.1尚未移植橄榄油；0.2.2已补齐公共轮廓与时序，接入见[橄榄油](橄榄油.md)，仍不以样例宣称全系列页面已升级。


## 顶栏展开搜索

`SharedExpandingSearch` 是鸿蒙端共用入口，产品提供图标、文案、颜色、动作时读取的动画和查询行为。默认只有同组圆形按钮，右端固定，展开时左端带按钮向左滑动，整条胶囊两端半径均为控件高度的一半。动画完成后按代次及存活状态请求焦点和键盘；回车与再次点击搜索按钮统一提交、隐藏键盘并收回按钮，查询由产品持有并保留。外部关闭和离页使旧聚焦回调失效。基础不读取产品偏好或数据。宫殿／建筑世界的首页和物品栏共用此组件。
