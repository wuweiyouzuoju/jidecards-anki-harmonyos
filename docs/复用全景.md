# jidecards 复用全景

由 `npm run audit:reuse` 从当前文件和已核对的职责映射生成。完整来源、消费者路径与 SHA256 见 [reuse-audit.json](../reuse-audit.json)。

最初的 12 个模块只是首批实现。当前已将图标绘制、原生图标按钮、按压、箭头与返回/历史资源接入魔方和空间训练；完整交接见 [公共 HAR 接入](公共HAR接入.md)。盘点仍包含 **22 类跨产品 UI/交互复用、5 类工程治理复用**，另有 4 类历史、机制或间接借鉴。三类含义不同，不合并为已经迁入本基础库的能力数。

## 其余可指引领域与接续顺序

菜单树/长按划选、目录选择、富文本/媒体、音频焦点、应用内助手、桌面卡片等已有闪卡内部复用和明确边界；本次没有把它们伪称为已经跨产品接通。继续查 ownership.md、extension-points.md 和 README.md，按 [跨产品接入规范](跨产品接入规范.md) 抽取规则。

优先补齐已在多个产品出现、但新基础还缺失的图标/按钮、设置/表单、帮助、标题与确认、转场/描边/色层和展开显露；现有业务能力保持原所有者。JideCalc、养个棋等本轮未找到明确闪卡来源标记，不能据此认定不存在未记录复用。

盘点命令只检查文件、来源记录和契约边界；各次实际产品行为/构建结果见 [公共 HAR 接入](公共HAR接入.md)，不能用该命令或首批测试证明整个清单已经通过行为和设备验收。
