# 跨产品接入规范

本页把[复用全景](复用全景.md)中已出现的跨产品做法整理为后续产品的接入约定。每类的来源、使用方和改造范围见全景及 [reuse-audit.json](../reuse-audit.json)。首批新模块只覆盖其中一部分，不能代替所有成熟实现。

## 选择来源与完成条件

1. 先明确用户能观察到的完整行为，查当前来源及至少一个真实使用方，再选择直接复用、适配或重建。目录名、相似外观和文件数量都不能证明覆盖完整。
2. 复用单位包含模型、控件、资源、平台宿主、状态发布与验证入口。只搬按钮或只改 token，不代表整个能力接通。
3. 在目标当前文档记录唯一责任入口、产品差异、依赖闭包与实际来源版本。未经说明，不以新基础中的简化实现覆盖目标已有能力。
4. 重建或迁移需要保留输入输出、失败、取消、禁用、读屏、长内容、主题和数据行为。自动检查与设备证据分别记录；构建成功不能代替行为等价。

## 图标与动作

- 图标资源、绘制、按钮热区和语义分开维护。同义动作复用现成 SVG，保留原透明度；描边色与内填色分别处理。
- 图标按钮保持完整读屏名称、禁用后的迟到点击守卫和实际热区。直接导航、菜单项与图片角标的颜色/位置有不同语义，不以统一函数抹去差异。
- 普通次动作、实色主确认、卡片底的学习/训练主动作、危险确认分别保留语义。不能用首批 ActionButton 代替所有按钮或取消危险文字。
- 普通按压由原生属性修改器提供；取消、恢复和禁用不残留缩放或底色色层。持续选中只反映真实设置，与按压反馈分别处理。

入口：ActionIcon、IconActionButton、普通按钮、主动作、主表面。

## 设置、表单与原生控件

- 动作行、开关行、选择行、数字输入和静态说明是不同职责。共用标题/说明层级、槽位和边界，不把所有行改成同一种点击行为。
- 标签占剩余空间并允许换行；普通选择器和完整路径选择器分别测量/限宽。外层边距、行间距和说明间距各有唯一贡献者。
- 原生 Select 需要同时核对显示值、可用候选、选中索引、菜单外底和手动明暗主题。非法索引、候选移除后的迟到选择和禁用回调不能触发业务。
- 设置行展示的“已保存”来自真实保存入口；保存失败、原值已变化与已保存但应用失败分别处理。UI 和助手共用该领域写入入口。

入口：SettingsActionRow、SettingsToggleRow、FormSelectRow、FormRowLayout、SelectStyle、LocalPreferenceWrite。

## 帮助、标题与弹窗

- 帮助按钮具有独立语义、读屏和点击隔离；帮助紧随对应标题，不能误触整行动作。
- 弹窗窗口宿主、表面外壳、标题/底部动作和内容各有责任。安全区与键盘来自窗口，正文预算扣除实际标题、动作和一次内边距，短内容收缩。
- 标题、关闭、确认和完成保持清楚的左右槽位；长标题与长操作文案不能裁掉关键后果。危险和多义动作保留可见文字。
- 关闭按钮、遮罩和系统返回进入同一产品关闭策略；先处理最上层、键盘或子弹窗。草稿、忙碌和已接受写入的结果由真实业务所有者决定。
- 原生窗口的创建、替换、销毁和旧关闭回调隔离不能由一个页面内表面组件代替；接入时一起验证反复打开、退出后回调和失败重试。

入口：帮助约定、DialogHeader、DialogFrame、NativeDialogHost。

## 表面、转场与展开显露

- 描边只管理轮廓，不覆盖底色、圆角或按压。语义色成对，菜单、选择、危险和业务编码颜色保留各自含义。
- 同一页面/弹窗一次转场；参数、当前档位、平台效果和展示宿主分别查清。不把换题、评分或常驻侧栏选项变化当作导航。
- 展开显露根据真实布局和当前滚动位置执行；用户回看、收起、切换内容或离页应取消旧意图。一次展开显露与持续聊天跟随是不同契约。
- 当前闪卡 ExpansionReveal、魔方 CubeScrollReveal 和舒尔特 ScrollReveal 已有不同的请求、延迟和布局处理；共同目标不代表行为等价。统一前保留各自晚到布局、用户滚动和关闭回归，不能任选一个复制后声称替换完成。

入口：SurfaceBorder、SurfaceTransition、ExpansionReveal、CubeScrollReveal、SchulteScrollReveal。

## 菜单、目录与富内容：按当前领域继续提炼

这些已有闪卡内部多入口复用，尚未被本次证明为跨产品整套迁入，采用前先界定领域差异：

| 领域 | 可以提炼的契约 | 保留的领域责任 |
| --- | --- | --- |
| 菜单树、锚点、长按划选 | 稳定 ID、实测定位、当前可用性、取消/多指/迟到点击 | 实际动作、危险确认和宿主显隐 |
| 目录与层级选择 | 完整路径、搜索、临时展开、稳定身份、布局 | 候选读取、草稿和真实写入 |
| 富文本、图片、音频与预览 | 选区/草稿代次、资源拥有者、释放、只读预览 | 卡片模板、媒体存储协议和产品格式 |
| 状态消息、撤销和加载 | 只展示真实阶段、有效期、重试条件、取消旧交互 | 写入是否完成及撤销是否仍有效 |
| 应用内助手 | 共用能力声明、实时状态、工具发现、权限与确认边界 | 产品领域操作和发布开关 |
| 桌面卡片、应用更新与系统评价 | 真正平台调用、跳转回退、发布事实与身份 | 各产品更新地址、文案及应用身份 |

以上继续查公共 UI 索引、领域责任、交互反馈与扩展入口。不把闪卡 Core、调度、权益发行、私有密钥、完整主题服务或媒体协议随“common”目录带入新产品。

## 验证与接手

源文件存在、资源哈希相同或公共控件被引用都只证明相应事实。目标产品完成时仍需说明实际行为检查、编译、设备观察及未覆盖范围，并让下一位 agent 能从当前入口找到实现、原因与复现命令。工程方面按[工程约定](工程约定.md)执行。

## 按钮组宽度与选择弹窗补充

按角色区分页签组、主动作、行内辅助、图标与选择框宽度；同组等宽等高并在窄屏/长语言下整体换行。选择弹窗保留稳定锚点、选项行和选中槽位，父状态刷新不得重建展示状态。完整约定见 [界面与交互](界面与交互.md)，iOS实现见 iOS系列规范。

普通枚举的原生选项菜单与内容弹窗、危险确认分别处理；保留原有系统外观，不能为修复交互问题换成大气泡内容面板。原生菜单使用持久锚点，父状态刷新不反复重建菜单。平台映射及尺寸责任见 [界面与交互](界面与交互.md)。

弹窗玻璃统一使用[弹窗玻璃规范](弹窗玻璃.md)与公共HAR的SharedGlassBackdrop，整块轻模糊与连续折射共用展开宿主。

玻璃图标（0.2.14）：SharedActionIcon.outlineOnly显式去掉SVG内填色，并将字符串语义tint转为不透明描边；strokeColor优先，默认描边仍由base/dark成对资源提供。产品玻璃菜单、设置与工具图标选择outlineOnly，扁平模式保持既有灰色填充。卡片星标/旗标等状态徽标可显式保留填色；不要通过改原始SVG或另一套Image绘制绕过公共图标入口。所有资源须有描边几何，纯填充图标不能未经适配直接使用此模式。
