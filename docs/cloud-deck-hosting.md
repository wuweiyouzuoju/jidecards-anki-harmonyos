# 云端牌组托管指南

> 新安装用户可领取首批牌组。应用读取版本化公开目录 `cloud-decks-20261105-final.json`，目录含原七项、中高考课标语音版、托福绿宝书和文言文实虚词，共十一项。所有牌组使用清晰的中文分发文件名，下载 URL 对中文路径做 UTF-8 编码。

> 现行运维文档。目录 Schema 以 `entry/src/main/ets/model/云端牌组模型.ts` 为准，
> 当前发布数据以 `hosting/cloud-decks.json` 为准；历史 plan/spec 不能覆盖这两处事实。

云端牌组功能不要求自建业务服务器。客户端只读取一个公开 HTTPS JSON 目录，再从目录提供的 HTTPS 地址下载 `.apkg` 内容。目录和文件可以放在 123Pan、GitCode、国内对象存储或其他能稳定提供下载地址的第三方服务。

## 1. 准备文件

把要发布的牌组导出为 `.apkg`。分发文件使用清晰的中文名称，例如：

```text
高考英语词汇（课标语音版）.apkg
```

中文文件名直接保留在云盘中，JSON 的 `downloadUrl` 使用经过 URL 编码的完整 HTTPS 地址。

托管链接必须满足：

- 使用 `https://`；
- 打开链接后直接返回文件，而不是带广告或确认按钮的网页；
- 不要求用户登录网盘账号；
- 允许 HarmonyOS 客户端直接访问；
- 最好长期稳定，更新牌组时优先发布新版本文件，避免静默替换旧文件。

## 2. 创建目录 JSON

仓库已经提供可直接上传的 [牌组目录](../hosting/cloud-decks.json)。目录中的每条记录对应一个独立 APKG；首次引导最多选择 3 个牌组，合计不超过 100 MB（104,857,600 字节），逐个下载并导入。加入官方 QQ 群 `726837065` 可免费下载所有牌组，再走本地导入。

2026-11-04 既有批次包含七项：中国法律专业版、小学古诗词、GRE红宝书词汇、中国古代文化常识、高中古诗词、初中古诗词、AI机器学习。旧 CET四六级词汇、高考英语词汇、中考英语词汇及 IT计算机下架；不恢复已删除的 AI for Science。ID、显示名、版本、字节数与卡片数以目录及 `cloud-deck-catalog.test.mjs` 为准。中国法律和 AI 文件与旧云端文件 SHA256 一致，复用原地址和既有版本；新高考与中考分包已在原直链目录上传，并从无登录地址完整读回，与本地 APKG 的大小和 SHA256 一致。旧目录地址继续供原客户端读取。

GRE 分发文件使用带“优化版”的独立文件名，避免已上传原包的 CDN 缓存混用。卡面改为“看词忆义 → 核对核心释义 → 按需展开用法、助记、字源”，不引入远程字体、脚本或新的卡片类型；保留笔记 GUID、字段顺序、卡片身份与学习状态。原包存在的 `extort` 字段错位、`spoor` 破损 HTML 和 `zesty` 不准确释义已修正，后者核对 [Merriam-Webster](https://www.merriam-webster.com/dictionary/zesty)；四个跨解码器兼容性异常的 MP3 保留原发音转为 WAV，清理可选字段中的“无”占位。检查覆盖 ZIP/SQLite、全部音频解码、Anki 26.5 的全量正反面渲染、媒体引用、重复导入及原包升级，以及实际应用 HTML 的宽窄屏、深浅色、放大文字和折叠交互；不代表全部释义已逐条人工校订或真机导入已完成。

```json
{
  "schemaVersion": 1,
  "decks": [
    {
      "id": "english-basic",
      "name": "英语基础词汇",
      "description": "适合入门复习",
      "version": "1.0.0",
      "accessType": "public",
      "downloadUrl": "https://你的文件直链/高考英语词汇（课标语音版）.apkg",
      "cardCount": 1000,
      "size": 1048576
    }
  ]
}
```

字段说明：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `schemaVersion` | 是 | 当前固定为 `1` |
| `id` | 是 | 唯一 ID，只用 `A-Z a-z 0-9 . _ -` |
| `name` | 是 | 软件中显示的牌组名 |
| `description` | 是 | 简短介绍，可为空字符串 |
| `version` | 是 | 展示版本，例如 `1.0.0` |
| `accessType` | 是 | 当前公开牌组用 `public`；未来兑换码牌组用 `redeem_code` |
| `downloadUrl` | 公开牌组必填 | HTTPS 下载地址；可带短时查询参数，也允许第三方 API 使用无扩展名路径 |
| `cardCount` | 否 | 正整数卡片数；填写后会在牌组条目中展示 |
| `size` | 否 | 文件字节数；首批可选文件必须填写正整数，下载完成核对大小 |
| `coverUrl` | 否 | 预留的 HTTPS 封面地址，当前界面不显示 |

`name` 是用户在软件中看到的名称，不要求与云盘文件名一致。每次替换 APKG 后，必须同时更新该条目的 `downloadUrl` 和精确字节数 `size`；否则客户端下载完成后会因大小校验不一致而拒绝导入。

目录本身也必须通过 HTTPS 直接返回 JSON。建议先在浏览器无痕窗口测试目录和每个下载链接，确认不依赖登录状态。

新增或下架牌组时只需修改这一个 JSON 并重新上传，不需要把已有 `.apkg` 合并，也不需要重新上传未变化的牌组文件。

## 3. 把目录地址写入应用

编辑：

```text
entry/src/main/ets/model/云端牌组配置.ts
```

将唯一配置值改成目录地址：

```ts
export const 云端牌组目录地址: string =
  'https://你的目录直链/cloud-decks.json';
```

重新构建软件即可。发布时先上传并校验每个文件，再上传版本化目录并逐字节校验，最后把公开目录地址写入应用。

## 4. 123Pan 与其他服务

如果使用 123Pan，应用中只填写公开目录和文件下载地址，不填写账号、管理令牌或上传接口密钥。如果当前套餐不能生成稳定直链，可以先使用 GitCode Pages、国内对象存储的公开读地址，或其他第三方文件分发 API；客户端协议无需变化。

托管平台发生变化时，只要新平台仍提供 HTTPS JSON 与真实的 `.apkg` 下载内容，就只需替换目录地址或目录中的下载地址。客户端不依赖 URL 的文件扩展名，下载完成后会检查 ZIP/APKG 文件头和可选的精确文件大小，再交给导入器验证。

系统下载任务若连续 90 秒没有新增字节，会自动取消并允许重试。下载先写入 `.part`，文件完整且校验通过后才改名为 `.apkg`；失败、暂停或超时立即清理，进程被系统终止留下的文件会在下次引导加载前清除并从头下载。

## 5. 后续兑换码

兑换码牌组不能把永久文件直链放进公开 JSON。推荐流程是：

1. 目录只发布 `accessType: "redeem_code"` 的展示信息，`downloadUrl` 留空。
2. 客户端向第三方兑换 API 提交牌组 ID 和兑换码。
3. API 验证后返回短时有效、一次性或限次数的 HTTPS 下载地址；路径可以没有 `.apkg` 扩展名。
4. 客户端继续复用现有下载与自动导入流程。

验证规则和签名密钥只能放在第三方 API 服务端，不能打包进应用。
