# `docs/` 与 `.agents/` 局部规则

## 适用路径

本规则适用于当前开发文档、Agent 规则、决策记录、工具说明和文档契约测试改动。

## 修改边界

- 当前规则只放在根 `AGENTS.md`、`.agents/` 和当前领域文档；历史计划、发布草案和 `.trae/` 不得发出当前执行指令。
- 事实优先读取源码、配置、锁定文件和测试；文档引用事实来源，不复制容易过期的统计数字。
- 跨模块或长期有效的选择写入 `docs/decisions/`，说明决策、原因、影响范围和验证方式。
- 文档新增入口、命令或边界时，同步更新导航和文档契约测试。

## 验证

- 运行 `npm run verify -- repo`，确认链接、当前规则、决策入口和历史归档约束通过。
- 发现版本号、测试数量或功能状态与源码冲突时，先修正事实来源或改为动态验证，不保留两个手工真相。
