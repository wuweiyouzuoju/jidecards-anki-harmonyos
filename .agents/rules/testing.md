# 验证约定

唯一命令与能力说明见 [验证说明](../../docs/development/verification.md)。

- `npm test -- <领域>` 是快速反馈；`npm test` 自动运行全部 `tools/tests/*.test.mjs`。
- 新业务规则直接 import 真实模块执行。平台适配可注入可控依赖；页面源码提取测试仅作现有过渡保障，不作为新增业务测试的首选。
- 保留协议、资源和依赖方向等必要静态检查；不锁死方法位置、注释或等价语法。
- `npm run verify -- repo` 是仓库门禁；`npm run verify` 增加环境、Rust 主机与完整 HAP 构建。任何阶段失败返回非零。
- UI/IO/媒体改动在已连接设备上覆盖安装后验证；不得 uninstall。没有验证的交互明确记录。
- 不追求测试数量。修复真实 bug 时先确认回归能抓住故障；修改后运行相应检查，最终做任务所需完整验证。
