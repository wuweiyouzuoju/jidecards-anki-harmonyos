## 当前实现

完整菜单与弹层已提取为公共 HAR，记得闪卡和记得记忆宫殿共同使用。接口、责任与实测锚点契约见[完整菜单接入](docs/完整菜单接入.md)。

- `Index.ets`：正式 HAR 的唯一导出入口。新增 `SharedPageBackground`、`SharedSurface`、`SharedActionButton` 和 `VisualTokens` 提供显式采用的系列视觉档；[视觉接入](docs/视觉基础接入.md)与[可运行样例](examples/VisualShowcase.ets)是当前入口。图标绘制、原生图标按钮、按压、折叠箭头及返回/历史明暗资源，由魔方和空间训练共同消费。产品保留主题资源解析、动效偏好、文案和业务动作。
- `consumers.json`：真实使用方及适配入口；构建前核对公共源码、HAR 和已安装包的一致性。

- `src/core/`：独立的几何、主题、按压/动效、日期和触感规则，不访问平台 Kit、AppStorage 或产品服务。
- `src/harmony/`：按钮、加载/空/错误展示、弹窗表面、系统主题读取和触感后端。状态、文案、窗口几何与业务回调由产品显式提供。
- `tests/`：执行实际纯规则和注入的设备边界，覆盖禁用点击、失败回退、坏输入、跨时区和安全区。
- `tools/`：文档/依赖/来源检查，以及独立 HarmonyOS 工程的无签名 HAP 编译检查。

普通按钮、内容状态、页面内弹窗等首轮重建模块仍是候选实现，未纳入当前 HAR 公共 API，不能取代产品已有完整组件。等级模块由[等级机制对话](docs/等级机制上下文.md)独立推进。完整覆盖与未迁入能力见[复用全景](docs/复用全景.md)。

## 验证

Node.js 24+，主机检查无 npm 依赖。在本目录运行：

```powershell
npm test
npm run check
npm run audit:reuse
npm run build:harmony
npm run sync:consumers
npm run check:consumers
```

HarmonyOS 编译需要本机 DevEco Studio；可用 `DEVECO_STUDIO_HOME` 指定安装目录。工具在 ASCII 临时路径生成独立应用和 HAR，实际调用公共 API，不读取产品签名或用户数据。HAR 输出 `.local/packages/jide_foundation.har`，源码及包哈希在 `.local/packages/report.json`；编译夹具记录在 `.local/harmony-build.json`。随后同步已登记产品的 ohpm 依赖，操作与验收见[公共 HAR 接入](docs/公共HAR接入.md)。

无签名 HAP 只验证 ArkTS/资源/应用编译，不表示安装、真机触感、读屏、像素、手势或所有设备窗口事件验收通过。系统主题适配使用 API 20+ 的设备资源入口；当前编译夹具采用已有项目使用的 API 21/23 范围，不构成所有更低 API 的兼容证明。

## 接入原则

先从[复用全景](docs/复用全景.md)和[跨产品接入规范](docs/跨产品接入规范.md)定位完整能力，再选择已重建模块或仍在当前产品维护的实现。普通 ActionButton、StateView 或 DialogSurface 不能代表完整按钮、设置、原生窗口或帮助体系。产品集中维护自身状态和资源，动效、配色、窗口宿主和业务后果保留明确差异。

移植时记录实际源文件 SHA256、目标路径、改造范围和验证结果，保留 AGPL-3.0-or-later 标识。规范是指导，目标项目的当前规则与用户已接受决定继续适用。

给后续对话的短提示词：

> 先读本目录 README.md，使用新基础及当前产品源码，按实际职责复用。

0.2.2新增正式公共橄榄油模块：群组融合、拉伸收颈、评分组分裂、轮盘吸附、连接片与可打断时序。实现和独立样例见[橄榄油](docs/橄榄油.md)。iOS的对应实现已统一纳入JideFoundation。

0.2.3修正玻璃的实际透射与背景层级，普通内容更实、操作按钮更通透；角色与参数见[视觉基础接入](docs/视觉基础接入.md)。闪卡取消橄榄油，保留正常产品交互。

新增弹窗玻璃公共实现 `SharedGlassBackdrop` 与 `warmSharedGlassSource`，来源为用户确认的闪卡首页版本。全弹窗推广入口见[弹窗玻璃](docs/弹窗玻璃.md)，尚未宣称各产品已全部迁移。

0.2.6：明暗弹窗共用真实背景折射，dialog雾面层参考iPhone17当前菜单；按钮和内容共用细边参数。Jidecards已通过薄适配接入首页菜单及牌组长按，其余迁移按规范继续。

玻璃融合圆角裁切：三角形的顶点全在圆角外或仅剩两个边界点，不代表曲线内部面积为空；GlassFusionTessellator用中点测试和有界细分保留弧内覆盖。tests/glass-fusion.test.mjs覆盖弧线与粗网格相切导致左上角斜切的回归，不能退回仅按顶点符号丢弃整个三角形。

GlassFusion球形中段：glassFusionStageRect在中段以同一直径圆球连接触发轮廓和面板，端点仍严格采用实测矩形。glassFusionTiming分别拥有展开与收起节奏，收起按72%时长从当前进度连续反向；减少动态效果直接终态。圆角测试同时覆盖平移到小数坐标的四角，避免仅原点样本通过而设备右下仍斜切。

文件选择、异步描述符复制与系统保存已从当前闪卡提炼，建筑世界／记忆宫殿通过专用版本接入；职责、来源及验证见[文件导入导出](docs/文件导入导出.md)。
