# 记得闪卡 JideCards

原文：https://jidecards.com/works/jidecards/

记得闪卡是面向鸿蒙 HarmonyOS NEXT 的原生开源闪卡应用，基于 Anki 内核，用于背单词、记忆知识点与备考。根据记忆情况安排间隔复习，支持导入已有的 Anki 牌组、同步学习进度和备份学习资料。

## 学习用途

- 背单词：把单词、释义和例句做成闪卡，或导入已有的 Anki APKG 词汇牌组；支持图片、音频和输入答案。
- 记忆知识点：把考试概念、公式和问答拆成卡片，用挖空卡回忆关键内容，用图像遮挡复习图中的信息。
- 间隔复习：先尝试回忆，再查看答案并按记忆情况评分。Anki 内核的 FSRS 调度据此安排后续复习时间。

## 功能概览

- 复习：Anki 学习内核、FSRS 调度、四档评分、撤销、埋藏与暂停。
- 卡片：普通卡、挖空卡、输入答案、图像遮挡；支持图片、音频与数学公式。
- 同步：AnkiWeb 集合与媒体同步，支持自定义同步服务器。
- 导入导出：APKG 牌组导入导出，集合备份与恢复。
- 管理：牌组层级、搜索、批量编辑、标签与学习统计。
- 桌面与外观：桌面服务卡片、学习提醒、主题色；提供幻彩限时主题色。
- JIDE 助手：软件内的全能助手：功能导航、学习分析、资料阅读、制卡改卡与设置协助。当前为默认隐藏的开发者调试功能。

## FSRS：根据回忆情况安排间隔复习

记得闪卡复用 Anki Rust Core 的学习与调度能力。FSRS 根据复习记录和记忆状态安排后续复习，支持目标记忆保持率及牌组选项；应用前端不另写一套调度算法。

学习时先尝试回忆，再显示答案，按实际情况选择忘记、困难、良好或简单。支持撤销上一次评分、埋藏暂时不想看的卡片，以及暂停和恢复卡片。背单词和备考知识点都可以沿用这套复习流程。

## 问答、挖空、输入答案与图片遮挡

普通问答适合单词释义与概念辨析，挖空卡适合回忆句子中的关键内容，输入答案可用于拼写练习。图片遮挡适合把示意图、结构图或标注图拆成多个回忆问题。

卡片支持图片、音频与数学公式。导入的 Anki 卡片模板通过 HTML/CSS 渲染；依赖桌面插件或特定客户端脚本的牌组需要单独检查，不能仅凭 APKG 导入成功就判断所有交互兼容。

## AnkiWeb：同步卡片、复习进度与媒体

使用同一个 AnkiWeb 账号，可以在鸿蒙端与其他支持 AnkiWeb 的客户端之间同步集合和复习进度。集合数据与图片、音频的媒体同步分别处理，也支持兼容 Anki 的自定义同步服务器。

普通同步会合并可合并的变化；需要全量同步时，由用户选择上传本地集合或下载云端集合。第一次迁移前应确认哪一端保存了完整资料，并保留备份。

## APKG 导入导出与 COLPKG 备份

已有 Anki 牌组可以通过 .apkg 文件导入鸿蒙端，也可以把牌组导出后用于其他兼容客户端。词汇、考试问答、挖空卡和带媒体的学习资料都可以通过牌组包转移。

APKG 用于牌组交换，COLPKG 用于完整集合的备份与恢复。恢复整库会替换当前集合，应按应用提示确认；同步便于多设备使用，独立备份则方便在误操作后找回资料。

## 牌组、搜索、批量编辑与学习统计

使用层级牌组和标签组织学习资料，通过 Anki 搜索语法查找卡片。支持字段编辑、卡片预览及批量管理，便于整理已有牌组，而不只是逐张背诵。

学习统计展示复习量、卡片状态、间隔和记忆相关指标，帮助了解当前学习负担。学习提醒和 HarmonyOS 桌面服务卡片提供日常学习入口。

## JIDE：软件内的全能助手

通过自然语言讨论学习、了解软件功能、阅读资料和管理卡片。JIDE 可以从牌组、浏览或学习页携带上下文进入，把功能导航、真实数据读取、资料处理和可确认的修改串联在同一对话中。

例如，从“整理这份 PDF 的知识点”开始，按页读取或 OCR，选择合适的笔记类型，再生成带来源的可编辑卡片草稿；也可以查看复习情况，随后打开统计或牌组选项继续核对。

当前 JIDE 为开发者调试功能，发布配置默认隐藏入口。需解锁并配置模型服务后使用；联网检索另需开启应用端联网并配置搜索凭据。具体能力以当前应用、工具与发布说明为准。

- 功能认知与页面导航：读取当前页面、菜单、设置与已接通状态，开始指定牌组学习，打开带搜索条件的浏览页、统计、设置、提醒、编辑或预览。导航复用应用真实页面。 示例：“开始学习四级词汇这个牌组。”
- 学习数据与复习负担：按全库或搜索范围读取复习次数、耗时、卡片状态、到期预测与有数据时的 FSRS 记忆率，查看卡片历史和牌组选项。到期预测与每日限额后的可学队列分别解释。 示例：“总结最近七天的复习情况，看看未来两周的到期分布。”
- 设置读取与调整：查看已接通的外观、备份、同步、语言和学习偏好；确认调整卡片字号、列表宽窄、学习触感、主题色或全库 FSRS。深浅色按明确指令切换并提供撤销，其他设置按工具目录区分读写。 示例：“把卡片字号调到 130%，关闭答题触感。”
- 资料阅读与系统 OCR：导入 PDF、办公文档、电子书、文本和图片，按页或分段读取资料，使用本地系统 OCR 识别扫描页，保存资料笔记。支持视觉的模型可接收页面图片，制卡草稿可标注实际读取的文件与页码。 示例：“读这份 PDF 第 5 到第 8 页，整理核心概念。”
- 制卡、改卡与标签：根据真实字段和模板生成问答或填空草稿，查找已有卡片后精简答案、补充解释、修改字段与标签。目标缺失时使用原生选择框，用户可继续编辑草稿并确认保存。 示例：“把这段材料做成 10 张问答卡，答案尽量简短。”
- 卡库、笔记类型与外观：提出牌组或笔记类型创建、卡片移组、批量删除、类型迁移、共享模板与卡片样式修改。展示真实影响范围；删除、类型迁移、共享模板和样式等高风险草稿需要二次确认。 示例：“新建一个“概念、解释、例子”三个字段的笔记类型。”
- 长期偏好与历史继续：确认保存全局或指定牌组的长期偏好，恢复历史对话、澄清、读取进度和待确认提案。达到执行预算时保留进度，可显式继续；结果未知的写入先检查现状。 示例：“以后给我制卡，答案尽量控制在两句话内。”
- 本地计算与数据整理：通过一次性 JavaScript 沙箱清洗、去重和计算显式 JSON 数据。计算有固定资源预算，不取得文件、网络、卡库或工具权限，结果保存仍走原有草稿确认流程。 示例：“把这份列表去掉前后空格，再去重并统计数量。”
- 公开检索与图片候选：独立联网开关下搜索与读取公开 HTTPS 网页文字；Wikimedia 图片候选带来源和许可，带图草稿确认后才下载导入媒体。网页读取不执行脚本或登录。 示例：“联网查找这个概念的公开资料，给出来源。”
- 官方教程与场景建议：按需检索随应用打包的 Anki 官方手册选章，解释 FSRS、搜索或模板；结合空牌组、搜索结果、学习阶段和已导入资料给出可选择的下一步建议。对话支持表格、数学及化学公式。 示例：“解释一下 FSRS 和目标记忆保持率，再告诉我在哪里查看。”

## HarmonyOS NEXT 原生界面与开源内核

导航、牌组列表、设置与统计界面使用 ArkTS / ArkUI 构建；Anki 的 Rust 内核通过 C ABI 和 Node-API 接入。卡片本身仍使用 Web 组件呈现模板、图片和公式，以保留 Anki 卡片的表达方式。

项目以 AGPL-3.0-or-later 开源，源码、构建说明和问题反馈入口公开。记得闪卡是独立项目，非 Anki 官方客户端；正式版能力以应用市场发布版本为准。

## 常见问题

### 支持哪些设备？

记得闪卡面向 HarmonyOS NEXT。通过华为应用市场安装，具体设备兼容范围以应用市场为准。

### 能继续使用已有的 Anki 牌组吗？

支持 APKG 导入导出、AnkiWeb 集合与媒体同步，以及 FSRS 间隔复习。迁移前备份资料，完成后检查样例卡、图片和音频。

### 免费吗？源码在哪里？

应用免费下载，以 AGPL-3.0-or-later 开源。源码可在 GitHub、Gitee 和 GitCode 查看。

### 记得闪卡是 Anki 官方应用吗？

记得闪卡是复用 Anki Core 的独立开源项目，非 Anki 官方客户端。
