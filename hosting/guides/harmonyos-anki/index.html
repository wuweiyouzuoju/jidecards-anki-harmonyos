鸿蒙上的 Anki：记得闪卡是什么，适合谁

记得闪卡（JideCards）是一款面向 HarmonyOS NEXT 的原生开源闪卡应用。它复用 Anki Rust Core 的学习与数据能力，使用 ArkTS / ArkUI 构建导航、牌组列表、设置与统计界面，让已有 Anki 资料可以在鸿蒙端继续使用。

对于寻找鸿蒙 Anki 客户端的用户，关键在于能否读取自己的牌组、延续学习记录以及正常显示卡片内容。记得闪卡支持 APKG 导入导出、AnkiWeb 集合与媒体同步、FSRS 间隔复习、普通卡、挖空卡、输入答案与图片遮挡。它是独立开源项目，非 Anki 官方客户端。

闪卡可以理解为一个需要先回忆、再核对的小问题。例如正面是一个单词和例句，背面是释义；正面是一道概念问题，背面是关键要点。主动回忆是使用方式，FSRS 是决定下一次复习时间的算法，APKG 是搬运牌组的文件格式，AnkiWeb 是多设备同步服务。

这些能力适合已有 Anki 牌组的人，也适合愿意把自己的教材、词汇和考试知识点整理成卡片的人。若只想即装即用，应先确认自己拥有可用牌组，或准备自己制作卡片。应用并不因为支持 Anki 格式就自动附带整个 Anki 社区的资料。

选择鸿蒙背单词软件时，可以考虑自己的资料来源和学习方式：已有词库、例句或自制词汇卡，闪卡学习会更方便；需要课程、老师反馈或大量口语练习时，还需要相应的内容与练习渠道。记得闪卡提供的是学习和管理卡片的工具。

先选迁移方式：牌组文件还是已有学习记录

只有别人分享的牌组文件、准备从头学习时，选择 APKG 导入。已经在电脑或其他设备上使用 Anki，并希望继续原来的学习进度时，优先通过同一个 AnkiWeb 账号同步。

APKG 导入不要求 AnkiWeb 账号，导入后可以在本地学习。AnkiWeb 同步需要网络和账号。下载牌组的分享页面与牌组文件是两回事：导入入口需要实际的 .apkg 文件。

开始前在华为应用市场搜索「记得闪卡」安装正式版，确认设备使用 HarmonyOS NEXT。下文的入口名称可能随应用版本调整，具体选项以当前应用界面为准。

安装与准备：确认平台、资料和已有数据

通过本页的华为应用市场入口，或在设备的应用市场搜索「记得闪卡」获取正式版。能否安装、支持哪些设备以及当前上架版本，以应用市场实际显示为准；源码版本可能比商店版本更新。

HarmonyOS NEXT 原生应用的安装包与 Android APK 不同。不要把 Android 客户端的 APK、桌面软件安装包或 GitHub 源码压缩包当作鸿蒙应用安装文件。日常使用优先从应用市场安装，开发者才需要按仓库文档准备 SDK 和构建环境。

迁移前先查看旧设备上的资料：有多少顶层牌组，是否包含重要图片或音频，是否已登录 AnkiWeb，复习记录是否需要保留。把这些确认清楚后再选导入或同步，可以减少重复搬运和后续整理。

如果新设备里已经添加了自己的卡片，它就不再是空集合。此时不能照搬「新设备直接下载」的流程；先备份新设备的数据，再决定如何与旧设备合并。

  1. 安装记得闪卡正式版，打开应用确认牌组列表可以正常显示。
  2. 准备好实际的 APKG 文件，或者确认已有设备已完成 AnkiWeb 同步。
  3. 需要保留旧记录时，先在旧设备做独立备份；检查备份是否按需要包含媒体。
  4. 为大文件预留空间与时间；初次导入完成后先检查样例卡，再开始大量学习。

把 APKG 牌组导入鸿蒙端

APKG 是 Anki 的牌组包，可以包含笔记、卡片、模板和媒体，也可能包含导出者的学习记录。导入自己的历史牌组与导入他人分享的资料，对复习进度的需求不同。

  1. 把 .apkg 文件下载到设备上容易找到的位置，确认下载完成；如果获得的是压缩包，先查看里面是否有实际的 APKG 文件。
  2. 打开记得闪卡的导入入口，使用系统文件选择器选中 .apkg 文件。
  3. 查看应用显示的导入选项。学习他人分享的牌组通常无需带入对方的复习进度；迁移自己的记录时，按需要保留进度。
  4. 等待导入完成并查看结果，再回到牌组列表，打开少量卡片检查文字、图片和音频，随后开始学习。

导入并不保证每个第三方模板的脚本都能运行。依赖桌面 Anki 插件的功能不会因为导入 APKG 自动变成鸿蒙功能；复杂牌组应先检查样例卡。

笔记数量与卡片数量可能不同：一条笔记可以按多个模板生成多张卡片，挖空笔记也可能生成多张。不要仅凭这两个数量不同判断导入失败。

FSRS 间隔复习：评分要反映真实回忆

FSRS 是根据记忆状态、复习记录和目标记忆保持率安排复习时间的调度算法。记得闪卡使用 Anki 内核提供这项能力，下一次到期时间会随实际评分变化。

打开一张卡片后，先尝试回答，再显示答案。没有想起来就选「忘记」；想起来但很费力可选「困难」；正常回忆选「良好」；轻松回忆选「简单」。看到答案后觉得熟悉，不等于显示答案前已经记住。

目标记忆保持率越高，通常意味着更多复习。开始时可以先沿用默认配置，积累自己的记录，再了解牌组选项与参数优化；不要直接复制其他人的 FSRS 参数。

如果同一个集合在多端使用，检查所有客户端都支持正在使用的调度配置。复习到期数量来自排期，不代表每天都必须一次完成全部新卡。

第一次学习与每天复习：建立可持续的流程

进入牌组后，按应用提供的队列逐张学习。先读问题并尝试回答，再查看答案；如果卡片需要输入答案，先完成输入，再核对。评分应基于刚才的真实回忆，而不是希望卡片多久以后再出现。

刚开始可以选择一个小牌组，或者限制每天新增卡片数量，观察几天后的复习负担。例如先尝试每天学习 10 张新卡，只是便于测试的起点，并非适合所有人的固定目标。已有大量到期复习时，应结合可用时间调整新增量。

不要把「今天没有新卡」理解为应用失效。新卡上限、牌组选项、当前队列以及卡片状态都可能影响今天看到的内容。先查看该牌组的设置和统计，再决定是否调整。

误评分时可以使用撤销。暂时不想学习的卡片可以暂停，需要时再恢复；埋藏与暂停含义不同，埋藏用于暂时移出学习队列，暂停则适合长期不希望安排复习的内容。

同步不是每答一张题就必须立即联网。评分会保存在本机集合中；如果在多台设备之间切换，完成一轮学习后同步，再在另一台设备开始前同步，更容易保持记录一致。具体自动同步时机以应用设置为准。

如果一张卡长期难以回答，应检查问题是否太宽、答案是否太长，或是否还没理解材料。把卡片拆小、补足上下文，通常比反复修改评分来强行延长间隔更容易维护。

用鸿蒙闪卡背单词：词库、例句与拼写怎样组织

用于背单词时，牌组可以按教材、考试或主题组织。已有 Anki 词汇 APKG 的用户可以先导入小部分检查；自己制卡的用户可以围绕单词、释义、例句和易混点组织字段。词汇来源的质量决定了实际学习内容，应用格式兼容不能替代内容核对。

一张卡尽量有明确的回忆任务。例如题面给出单词和一句例句，要求回忆当前语境中的释义；另一张卡给出中文或例句空缺，要求回忆英文。两个方向产生的练习不同，可以根据实际需要选择模板。

拼写输入适合检查能否准确写出单词。识别词义与正确拼写是不同能力，不必让每张词汇卡同时考查所有内容。若只需要阅读识别，可以优先减少不必要的输入负担。

带音频的牌组可以用来核对发音，但音频是否存在取决于牌组媒体。导入后先检查几张含声音的卡；声音缺失时先检查文件或媒体同步，不要把更改 FSRS 参数当作音频修复方法。

对于一词多义，尽量让题面说明语境，否则一个单词对应很长的中文列表，容易出现不知道应该回答到什么程度的问题。遇到易混单词，可以增加区分问题或例句，而不是让所有含义堆在同一张卡上。

CET 四六级、考研、雅思或其他考试词汇都可以作为制卡材料，但记得闪卡本身不保证某个第三方牌组覆盖完整考纲。导入前检查牌组来源、说明与适用范围，学习计划还应包括实际阅读和使用。

记忆知识点：问答、挖空和图片遮挡怎样选

概念辨析适合普通问答。例如题面问两个概念的关键差异，答案保留必要的区分点。定义、流程和公式适合按明确问题拆分，不必把整页教材直接做成一张卡。

挖空卡适合围绕上下文回忆关键术语、条件或结论。一个句子可以含多个挖空位置，但每一张生成的卡都应有足够线索。如果题面只剩一句缺乏上下文的短语，就很难判断自己是否理解了知识。

图片遮挡适合图中的位置、名称与结构，例如示意图标注。需要先有清晰的原图，再把需要回忆的区域遮住。过小的字号、低清晰度图片或一次遮住大量区域，都会增加与记忆目标无关的阅读困难。

数学公式可以作为卡片内容，图片、音频也可以提供上下文。复杂公式或自定义模板导入后要检查实际渲染；不同设备屏幕与字体可能影响显示效果。

闪卡更适合巩固已经理解的内容。对推导、长篇论述或开放题，可以把关键步骤和判断条件做成卡片，同时保留完整材料用于理解和练习。评分时根据题面的具体问题核对，不必要求逐字复述所有背景。

Anki 卡片兼容性：模板、音频、图片与数学公式

APKG 包含牌组数据，但牌组的实际显示还取决于笔记类型和卡片模板。记得闪卡使用 Web 组件呈现卡片 HTML/CSS，原生界面负责导航和管理；这两部分采用不同的呈现方式是为了保留卡片模板的表达能力。

普通文字、图片、音频、挖空和公式属于常见卡片内容。依赖桌面插件、系统路径、浏览器特定行为或某个客户端约定的模板，应单独检查。支持 Anki 数据格式并不代表桌面 Anki 的插件生态可以原样运行。

检查媒体时，可以先确认同一张卡在原设备上是否正常，再核对导出时是否包含媒体、导入是否完成、AnkiWeb 媒体是否已同步。直接链接到外部网站的图片或声音还需要相应网络和资源可用性。

如果正面正常而背面空白，可以查看笔记字段是否有内容、模板是否引用了正确字段，以及是否依赖额外脚本。不要先批量删除卡片；保留一份样例和原牌组更便于定位。

反馈兼容问题时，提供应用版本、设备平台、最小样例牌组和预期显示，比只描述「不能用」更有效。样例中避免放入自己的账号、个人笔记或不便公开的资料。

整理牌组与卡片：搜索、标签和批量编辑

层级牌组可以按课程或主题组织，标签可以跨牌组标记来源、章节或需要整理的内容。两者解决不同的问题：牌组提供学习入口，标签帮助筛选；不必为每个小属性新建一个牌组。

卡片浏览器支持 Anki 搜索语法，可以按牌组、标签或内容定位资料。进行批量处理前，先检查当前搜索结果和选中范围，再执行改牌组、编辑或其他管理操作。

字段编辑影响笔记内容，模板决定卡片如何展示。同一条笔记可能生成多张卡片，修改字段后多张卡的显示会一起变化。需要调整结构时，先弄清笔记类型与卡片模板的关系。

暂停、恢复、删除和改变牌组不是同一件事。如果只是暂时不学习某些内容，可以先使用暂停，保留资料和记录。批量删除或模板结构调整前创建备份，有助于在结果不符合预期时恢复。

从多个来源导入资料后，先用少量搜索与标签整理建立清晰分类，再扩大批量操作范围。好的分类应方便你找到要复习的内容，而不是增加维护负担。

复习统计、学习提醒与桌面服务卡片

统计可以帮助查看复习量、卡片状态、间隔和记忆相关指标。比较数据前先确认查看的是同一个牌组范围与时间范围；全库统计和单个牌组统计回答的问题不同。

未来到期预测反映当前排期，之后的评分、新增卡片和设置变化都会影响它。预测并不承诺你在某一天一定只需要复习固定数量的卡。

卡片数量、笔记数量和当天复习次数也不同。一条笔记可能生成多张卡，一张卡可能在同一天被复习多次。统计数字不同，往往需要先核对单位和范围。

学习提醒和 HarmonyOS 桌面服务卡片提供进入学习或查看摘要的入口。它们帮助安排日常习惯，具体显示与配置以当前应用版本为准。用提醒建立固定时间，比把每个统计指标都当作成绩更容易持续。

如果每日负担持续增加，可以查看新卡数量、目标保持率和已有到期卡，适度减少新增内容，并检查困难卡的质量。统计更适合辅助调整流程，而不是只追求某个更大的累计数字。

通过 AnkiWeb 延续多设备学习进度

如果其他设备已保存了完整集合，先在那台设备完成 AnkiWeb 同步，再让鸿蒙端下载。一次从旧设备迁移到空的新设备时，不需要先把相同牌组再导入一遍。

  1. 在已有资料的客户端确认卡片和媒体完整，创建一份独立备份，再登录 AnkiWeb 完成同步。
  2. 在记得闪卡设置中的同步入口登录同一个 AnkiWeb 账号，并确认媒体同步选项符合需要。
  3. 发起同步。如果出现全量上传或下载选择，按下方的方向说明确认，等待集合与媒体同步完成。
  4. 检查牌组、复习进度及几张带图片或音频的卡片；以后切换设备前后及时同步，减少两端各自积累未同步修改。

全量上传：以本机集合替换云端集合。全量下载：以云端集合替换本机集合。如果完整资料在 AnkiWeb、鸿蒙端还是空的，应选择下载。如果两端都有独有内容，先分别备份并整理合并方案，不能靠随意选择一个方向保留两端资料。

普通同步可以合并可合并的变化；字段或模板结构等变更可能要求全量同步。集合完成后媒体仍可能继续传输，文字出现并不代表音频和图片已全部下载。

使用自建同步服务时，服务器需要兼容应用使用的 Anki 内核，并使用该服务器的账号。具体地址和兼容性要求见应用内同步说明。

牌组导出、整库备份与同步有什么区别

需要交换或分享某个牌组时，导出 APKG。需要完整保存个人集合时，使用 COLPKG 备份并按需包含媒体。恢复整库会替换当前集合，操作前核对文件和应用提示。

同步解决多端保持一致的问题，也可能传播删除和其他修改。备份保存某个时间点的副本。模板修改、大批量编辑或迁移设备前，保留一份独立备份更方便回退。

三个实际迁移场景：按资料所在位置操作

场景一：下载了一份 APKG，第一次使用闪卡
安装记得闪卡 → 下载完整 APKG → 导入 → 检查样例卡与媒体 → 从少量新卡开始。暂时只在一台设备学习时，可以先不配置同步，之后再决定是否使用 AnkiWeb。
场景二：电脑已用了很久，鸿蒙端是空的
电脑独立备份 → 电脑同步到 AnkiWeb → 鸿蒙端登录同一账号 → 需要全量同步时下载云端集合 → 等待媒体完成 → 核对原牌组与学习进度。完整资料在电脑或云端时，不能从空的鸿蒙端全量上传。
场景三：两台设备各有自己的新增卡片
先分别备份并暂停随意覆盖。确定统一集合，借助兼容客户端的 APKG 导出与导入整理独有资料，检查内容和记录后再同步到 AnkiWeb，随后让另一端下载统一集合。合并结果需要核对，不存在一个无需判断就能保留所有冲突内容的按钮。

导入与同步的常见问题

选不到 APKG 文件
确认保存的是实际 .apkg 文件，而非下载页面、链接文本或尚未解压的外层压缩包，再从系统文件选择器定位下载目录。
导入后没有图片或音频
先确认原牌组包含媒体，检查导入结果；通过 AnkiWeb 迁移时，检查媒体同步是否开启且已完成。缺失的源文件不能靠改评分或重新排期修复。
卡片样式或按钮与电脑不同
查看模板是否依赖桌面插件、特殊 JavaScript 或特定客户端能力。先用简单卡片判断基础导入是否正常，再向牌组作者或项目反馈模板问题。
首次同步要求上传或下载
先确认完整集合在哪一端。云端完整、本机为空时下载；本机完整、云端为空时上传。两端各有独有资料时，先备份，不直接覆盖。
导入后到期时间与预期不同
检查是否带入了原牌组的学习记录，以及当前调度和牌组选项。学习别人分享的资料通常应从自己的学习记录开始。
重复导入后数量没有成倍增加
导入器会识别已有笔记并按导入策略处理，并非每次都生成一份完整副本。先查看结果，再检查已有内容是否更新；笔记类型变化也可能影响更新。
换设备后卡片存在，但学习进度不对
确认是否通过同步迁移，或是否在 APKG 导出和导入时按需要包含了自己的进度。仅有卡片内容不等于一定包含完整复习记录。先保留原设备的数据，再检查迁移方式。
同步提示失败
先检查网络、账号与应用显示的错误。自建服务器还需核对地址和兼容性。重新尝试前保留本机资料，不要通过删除集合或随意全量覆盖来处理网络错误。

鸿蒙 Anki、FSRS 与背单词常见问答

鸿蒙能用 Anki 牌组吗？
可以在支持 Anki 格式的鸿蒙原生客户端中使用。记得闪卡支持 APKG 导入和 AnkiWeb 同步；第三方模板是否完整兼容，需要用具体牌组检查。
HarmonyOS Anki 和记得闪卡有什么关系？
HarmonyOS Anki 通常表达用户想在鸿蒙上使用 Anki 学习资料的需求。记得闪卡 JideCards 是满足这类需求的独立开源应用，复用 Anki 内核，不是 Anki 官方发布的鸿蒙客户端。
记得闪卡是免费的鸿蒙闪卡软件吗？
记得闪卡可从华为应用市场免费下载，源码以 AGPL-3.0-or-later 开源。主题活动及具体权益以应用内说明为准。本文的免费下载指应用获取方式。
鸿蒙 APKG 导入必须注册 AnkiWeb 吗？
本地 APKG 导入不要求 AnkiWeb 账号。希望多设备同步时，再注册或登录 AnkiWeb。先导入再学习与先同步旧设备集合，是两个可以按需选择的流程。
离线可以背单词和复习吗？
已经保存在本机的卡片和媒体可以用于本地学习。下载应用、获取网络资料和 AnkiWeb 同步需要网络；卡片若引用外部在线资源，相应内容也需要网络。
FSRS 鸿蒙端和电脑端会各算一套记录吗？
记得闪卡复用 Anki 内核并同步集合与复习记录，不另写独立调度算法。实际排期仍受集合配置、评分以及各客户端版本影响，多端使用时应保持支持的配置一致。
可以把 AnkiDroid 上的资料带到鸿蒙吗？
已有资料可以通过同一 AnkiWeb 账号迁移，或在兼容客户端中导出 APKG 后导入。Android APK 不是 HarmonyOS NEXT 的原生安装包；这里迁移的是学习资料。
支持 Anki 就能使用所有桌面插件吗？
不能据此推定。桌面插件、模板脚本和牌组文件属于不同层面的能力。记得闪卡支持的牌组格式与学习能力，不代表能安装或运行所有桌面插件。
鸿蒙背单词用普通卡还是挖空卡？
回忆词义可以用普通卡，回忆例句中的单词可以用挖空，检查拼写可以用输入答案。按照需要训练的能力选择，不必把所有练习塞进同一张卡。
软件支持图片遮挡和数学公式吗？
记得闪卡支持图片遮挡以及卡片中的数学公式。具体资料仍需要可用的原图、模板和媒体，导入后应检查样例显示。
JIDE 助手能做什么，是否已经开放？
JIDE 是软件内的全能助手，覆盖功能导航、学习数据、设置、资料阅读与 OCR、制卡改卡、笔记类型及外观、长期偏好、本地计算和公开检索。当前发布配置默认隐藏入口，可供开发者调试；需解锁并配置模型服务，联网工具另有开关和搜索凭据。具体能力以当前应用和发布说明为准。
只有鸿蒙手机能用吗？
项目面向 HarmonyOS NEXT，具体手机、平板或电脑能否安装及使用哪种版本，以华为应用市场的设备适配信息为准，不从源码支持推定某台设备一定可安装。

迁移完成后，最后检查这六件事

  1. 牌组完整：应有的顶层牌组和子牌组都能找到。
  2. 内容正确：普通问答、挖空和自定义模板各抽几张检查。
  3. 媒体可用：图片与音频存在，媒体同步已经完成。
  4. 记录符合目标：需要保留历史时检查学习进度，从头学习时不要带入他人的进度。
  5. 多端一致：使用同一账号同步后，两端能看到预期的集合，下一次切换设备前后及时同步。
  6. 备份独立：重要操作前的备份保存在可以找到的位置，按需要包含媒体。

完成这些检查后，再逐步增加学习量。以后遇到问题，可以从本文对应章节定位：文件与导入看 APKG 部分，复习排期看 FSRS 部分，换设备看同步部分，资料找回看备份部分。
